# 论文主张边界

当前已可用于 development 报告的主张：固定生成器下的 pre-evidence memory/strategy resource allocation；在 synthetic development 上的回复质量—记忆适切性—成本权衡；validation-only 选择规则和 strong-rule / fixed baselines 的内部比较。

仅在对应冻结实验完整跑通、attestation 绑定且统计检验通过后才可主张：ESConv strategy routing / false-memory abstention；EvoEmo / ES-MemEval-style 全 18 用户外部长期记忆评测结果。

不可主张：真实 distress 改善、临床安全、危机识别、POMDP、RL/RLHF、多模态、记忆写回、端到端生成模型提升、直接超过 D2RCU/RLFF-ESC，或“完全 untouched”的 EvoEmo（此前研发已分析其分布）。

若 PM 不超过 strong rule，应如实报告规则足够；若只在质量非劣时降低成本或降低某类风险，应主张效率、trade-off 或 memory-use reliability，而非普遍回复质量提升。
