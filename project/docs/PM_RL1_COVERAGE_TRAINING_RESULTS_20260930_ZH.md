## 3. 行为结果：有明确负例，没有独立收益证明

固定的六个 dev 前缀 × OFF/R/L × 四版本，共 72 条回复全部完成且自然结束。逐对输入完全相同，使用同一 greedy 解码和原生 EOS/EOT，没有任务级输出硬上限。所有回复均保留，逐条件开发观察已记录；没有生成胜率或把开发者判断当独立人评。

### 3.1 最明确的退化：助手开始编造个人经历

开发前缀 15 中，原始对话此前的支持者说自己的母亲也干预交友，用户问“你怎么处理的”。当前回答者是 AI，不能继承原支持者的人生。

- **OFF：**基础模型明确说明自己没有个人经历；epoch 1 还会道歉澄清。epoch 2/3 则编造与母亲谈话、争取自由及关系改善。
- **R：**基础模型没有继续自传；三个训练版本均编造自己与母亲的经历。epoch 1/2 的虚构只有 20 tokens，epoch 3 扩为 139 tokens。
- **L：**基础模型说明自己没有实际处理过此事；epoch 1/2 避免编造；epoch 3 编造谈话、妥协及母亲承认犯错，长达 284 tokens。

这是**同一个前缀在三个资源条件下的失败**，不是三个独立用户样本。所选 checkpoint 的 OFF 也退化，因此不能只归因于资源误用；短答和长答都可能出错。源 MS 中旧支持者确有自述，也不构成当前 AI 自传的依据。

### 3.2 记忆提及不能直接证明学会了资源增量

- 17/R 中四版本都会提到 MP 里的姐姐 Annie，基础模型本来就具备这一行为。不能将其记为本轮训练才获得的能力。epoch 2/3 避开了基础模型/epoch 1 的 always 扩张，仍需独立评估这种差别是否有实质价值。
- 14/R 中基础模型明确使用了 MS 的治疗经历；训练版本主要是泛化鼓励和提问，没有表现出更明确的历史利用。少提历史也不能自动判差，需看当前需要。
- 18/R 的 epoch 3 提到 Annie 与可选散步，但没有明确引用“以前喜欢散步”的独有事实，普通建议也能产生相同文本；不能据此证明利用了这条历史。
- 16 的各版本都尊重当前实际发生的朋友联系，没有沿用旧“尚未联系”的状态。这是正常表现，不能只给 LoRA 记功。

### 3.3 裁判还需要区分真正错误与过度指控

14/L 的 epoch 1 把 RS 中 appearing weak 变成对用户具体恐惧的确定解释；当前并未明确说这一点，应记录未确认解释，不能说已被相反证据推翻。

13/R 的 epoch 3 说用户已 speaking up about the harassment and seeking support。这可能指向支持者倾诉，原始 MS 支持这种解释；不能自动扣成“虚构已向 HR 举报”。但它再次建议 HR 时没有回应 MS 中既有后果顾虑，适当性仍值得检查。

这样的例子同时要求裁判识别错误、避免误报。正常共情、可选建议、模糊预设、具体事实和当前任务适配不能全靠关键词判定。

## 4. 如何推进，避免再一轮无止境训练

这次已经有一个可重载、可比较且失败可检查的版本：`X_l_coverage_20260930_v1`。冻结 epoch 3、基础模型、同提示渲染、数据、训练与生成身份，作为研究结果保留。**不把它命名为“已经改善支持质量的执行器”，也不因负例再挑另一个 checkpoint。** 本轮有限训练到此收口。

下一项主工作转入 R04B 测量：

1. 已把全部 18 个固定 dev 条件的基础模型／所选 LoRA 对照整理成开发材料，没有只选有利配对。每对共享完整合法过去证据，A/B 顺序按 hash 固定；模型身份、资源数量、开发意见和可见输入映射存放在单独私有 key。
2. 这些是 **6 个已见开发前缀、3 个 owners** 的材料池，不是独立确认卷，也没有人工偏好金标准。还需与既有来源错误、单点损伤、风格控制合并，并核验候选裁判的官方接口和完整证据容量，再冻结有限运行清单。
3. 沿用已定的最多 Prometheus-2 7B 与 Skywork Reward V2 两个候选范围，先检验它们能否区分上述真实错误、正常变化、等效和无法判断。不能按 ON 胜率或哪个更偏爱 LoRA 来选裁判。
4. 先保留原始分项与不确定性，不直接创造新的 scalar reward。自然支持 PPO 仍等待有效测量范围及 reward 映射；本次没有运行它。
5. 人评仍按 [一次集中活动的用途约定](PM_RL1_R04B_MEASUREMENT_AND_SINGLE_HUMAN_CAMPAIGN_20260929_ZH.md) 留给冻结系统终评。本轮没有新人工问卷，也没有把开发材料交给人重新校卷。若后来要用人工答案改 reward 并重训，就不能同时把同一答案继续叫独立终评。

因此，现在不是再次回到“先找一批回复试试能不能训练”。训练阶段已有真实结果；接下来要解决的是**评价能可靠测量哪些差别，以及能据此支持什么研究结论**。没有正向收益时按负结果或有限结论收口。
