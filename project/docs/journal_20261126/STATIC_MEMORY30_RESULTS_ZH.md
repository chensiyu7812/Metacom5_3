## 3. 配对变化与失败归因

STOP→MS有5个确定完整修复（T04/T06/T07/T09/T13），6个保持确定成功（T02/T03/T08/T10/T11/T12），T15两臂均失败；T05/T14可能修复、T01可能退步，均保留未知。没有按结果改样本、规则或执行条件。

|实际案例|已确认的问题或边界|归因|
|---|---|---|
|T04/T06/T07/T09|STOP缺所问历史事实；MS供证后完成必要回忆|来源可用性与获取增量；合理不回忆不等于事实任务完成|
|T07 STOP|在明确禁止问题的事实题末尾追问|可确认的要求执行失败，独立于缺证据|
|T13 STOP|只给一般安排/计划说明，没有明确所问的已安排阶段；MS明确回答|阶段信息不充分；不将其称为已证实未来泄漏|
|T15 MS|必要证据完整供应，回答却比较心理负担与缓解，漏掉明确要求的早期行动阶段|G偏离当前比较目标的应用/表达失败；不能归咎于这题检索遗漏|
|T01 MS|实质两项正确，附加背景确在实际历史输入中，但不在用户限定的当前摘句中|真实性与来源使用范围不同；保留范围争议，不判虚构|
|T05 STOP|一般鼓励合法，但是否足够简短未决|开放式长度要求的评价不确定，不事后发明字数阈值|

三处完成状态未知是T01/MS、T05/STOP、T14/STOP。另两处不确定（T06/STOP的draft、T15/MS的能力断言）仍逐项保留，但各自已有明确未完成项，所以整体为0；不是把unknown强行记0。

针对六个具体解释片段进行了遮蔽策略身份的第二次助手阅读，完整output对象hash和text逐字一致。它不是新的资格测试、不是独立人评，也不替代原五项待真人复核。T05/MS的简短一般鼓励在复核后被记为开发pass；其他争议保留，包括第二读者对T14/STOP采取更严格解释的分歧。原草稿与最终记录均保留，评价合同没有更改。不得将这份小开发观察直接接入正式reward。

## 4. 选择收益必须和未知、失败分开

C1仅在T02/T11改选STOP，两题两臂都确定成功。相对固定MS，三个通道完成差均为`[0,0]`，节省**7075输入tokens**，全来自共同成功题；没有拿失败题的节省充数。这满足上一轮预先声明的本批保守开发效率信号，但只有两次选择、三个已暴露来源家族，不能声称规则已普遍有效或具有长期支持收益。

简单基线改选7题STOP，总输入节省24191。其中五个共同确定成功题节省18335；T01/T14两个未知选择节省5856。其事实通道差`[0,1]`、自然支持差`[-1,0]`、联合差`[0,0]`，总配对差`[-1,1]`。即使总完整区间也为13–14，仍不能宣称相同质量；同物理端点的未知抵消，不同回复的未知不强行关联。

固定STOP相比MS少读51712 tokens，但其中17018来自五个确定损失题，3043来自双失败题，9881来自未知选择；只有21770来自六个共同成功题。这个对照说明少读本身不是研究目标。

## 5. 本线收口决定

这批支持“读取应受当前目标约束”的有限开发判断：事实需要和支持需要不能混成固定复述清单；不读可以成功；取到正确证据仍可能答非所问。C1出现小范围的保守效率信号，简单词规则仍有未知代价。停止围绕这15题继续扩样、改提示或调C1追正结果。

此结果没有读后动作，自然不能作为完整序贯必要性的正证或反证。后续进入独立SEARCH/EXPAND/STOP机制，直接研究已读内容怎样改变查询、可行候选、停止及最终任务。保持旧负结果、MP/ME pending/mask、自然支持外部验证和五项真人复核状态；不训练BC/PPO或新G。
