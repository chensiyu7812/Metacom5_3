## 评价职责

| 层 | 可程序核验 | 需要语义审阅，不能自动由程序替代 |
|---|---|---|
| 运行和来源 | 原始输出、EOS/length、严格JSON、schema、SHA、来源坐标/说话人/时间合法、调用预算、版本父链 | JSON合法不是理解成功；引用存在不是蕴含 |
| 中间解释 | 来源ID是否在实际观察中；原文逐字定位；父版本是否同目标且在先 | 主体、否定、计划/尝试/执行/结果、事件时间、当前目标、冲突/适用性、遗漏和过度推断 |
| 终局目标 | 已明确形式约束、可确定字面结果可单列 | 忠实同义答案、主体归属、范围限定、未请求的历史侵入、用户自主性、自然支持质量 |
| 获取与停止 | 本阶段实际固定工具轨迹与供应量 | 无自适应策略，不由来源命中推导正确动作 |

保留`pass / fail / unknown / equivalent / not_applicable / technical_failure`。技术失败和语义unknown单列；unknown不记0分。分别报告明确下界及包含unknown的上界，同时显示unknown分母。配对结果包括修复、保持、退步、无法确定；不是简单比较平均复述率。

Q01沿用的历史引用组能定位原文，但不能证明精确日历解释；原参考不改写，新合同将该语义项保留uncertain，未确认前不得算A2修复。Q06官方不可回答口径保留；“未在目前证据见到”与“全历史不存在”必须分开。Q03当前引用可作为它所询问的“记得的决定”的有界证据，不能据此证明决定已执行；Q04同理是引用中的安排和时间，不是后续效果。当前提问、假设或引用中的文字匹配不自动成为个人事实。

自然支持不要求复述全部历史。Q02/Q07/Q08中合适的当前回应可以完全不使用历史；事实信息只在使用时要求正确。事实/联合任务中明确要求的答案项才是必要完成条件，合理缺证拒答与完整目标完成分列。

## 时间测量

沿用GE2同boot单调时钟：请求入口、实际检索/展开/合法性检查/renderer/tokenization、解释调用开始/内部首文字/结束、解释可用与解析结束、PM结束、G开始/内部首非空文字/结束、请求完整完成。保留输出观察器、约束mask、IPC及实验守卫的包含区间，不把嵌套阶段重复相加。

S0和S1分别是两个真实可执行请求条件。S1报告该时点增量延迟及前态解释构建成本，必要时另报告两次观察更新的累计解释成本；S0的反事实终局生成不加入部署成本。每个终局实际执行，不能用质量端点复用冒充缓存延迟优势。

模型加载、冷首调用、常驻路径分开，固定执行顺序无warmup；不同臂的时间差不能被夸大为随机化因果估计。报告逐题配对、共同成功状态时间变化、nearest-rank P50/P95，16状态相关性明确。模型内部首文字不是客户端首文本或Tokkio有效语音；后两项未测。600秒Agent上限/300秒终局预留是实验守卫，未验证为用户体验阈值。
