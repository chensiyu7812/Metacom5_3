## 2. 为什么旧visible-query rule从未STOP

原规则用`earlier / previous / last time / before`检测Memory需求，再用help关键词选择MS或MS+RS。24题全部命中历史词，12题虽然当前已经完整引用相关报告，仍含“earlier statement”。旧规则没有“当前语境已经提供内容且任务只针对该内容”的覆盖条件，所以实际是18 MS、6 MS+RS、0 STOP。这里首先是一个可见信息判别缺口，不是需要更复杂RL的证据。

读取资源前可以观察：当前消息的原文、是否给出报告、请求是否明确只针对这段报告、是否另问当前未给出的历史内容、是否要求行为或仅回顾。不能观察：未读MS里的答案、隐藏供证分、需求层标签、gold、owner ID、任务ID或后来生成是否成功。历史指代不等于信息缺失，用户要求帮助也不自动等于需要RS。

提出且只保留一个最简单候选**C1**：当前消息明确提供一段报告，请求限定为反映/确认该报告，且未另问其他历史内容时选STOP；其他情况请求MS，仍服从原合法性与预算掩码。实现只接受可见query字符串，没有访问资源或评价的接口。当前英文模式较窄，识别不了的措辞回退MS；它不证明一般语义充分性。

这是看过J06后的新开发候选，未改原冻结规则。事后回放C1选择12 STOP、12 MS，输入14,498，联合完成16–19/24；相对固定MS配对差[-3,0]。J10出现确定退步，J20/J24丢失已知或可能完成，J04可能改善。因此**当前信息存在并不足以保证省掉MS后G仍满足原全原子口径**。不再按这些结果添加只修J10的词、数量阈值或任务例外。

独立来源验证方案已记录在`C1_RULE_AND_VALIDATION_PROPOSAL.json`：排除全部J06来源家族及变体，保留原family closure与split。历史test fold 6的3个来源家族继续封存，本轮不读其正文、不生成新任务；若其他研究线已有开发暴露，须如实记录，不能称从未见过的数据。后续若采用该方案，应在任何新生成前冻结来源、任务、评价和C1，覆盖当前充分、历史缺失、当前部分/另问历史、不需要个人事实四种情况；使用多种措辞，不能让“supplied in full”成为唯一捷径。

验证比较固定STOP、固定MS和冻结C1；按来源报告配对成功变化、已成功任务上的成本减少、失败节省、unknown及新错误。新受控任务应明确要求哪些事实，另保留自然支持评价，不能暗中要求所有简短确认都重述每个数字。3个来源组精度有限，不能按任务iid宣称非劣；任何确定成功损失都必须保留并限制效率主张。不使用本批24题确认候选，也不为该方案新增GPU申请。

## 3. 序贯获取与Generator的Step-2是不同问题

现有J06固定了每题的初始query、检索池和四个资源子集；MS+RS走固定MS→RS，最终渲染是固定子集形式。没有让策略依据新读到的文本决定第二个资源，也没有在相同初始可见信息下操纵不同合法读后证据、再比较OneShot/NoText与条件策略。上述STOP/MS选择只发生在读取前。因此，**当前不能证明读后序贯决策优于静态选择**；特权子集选择差距本身也不是序贯优势。

Generator的显式Step-2则是在已拿到同一资源后，是否通过独立的证据—目标检查改善最终回复。已有输出只能证明某些事实或动作没有表达，不能直接观察G究竟没有理解、理解后未选择，还是在压缩表达时遗漏。即使显式Step-2有效，也不等于读后资源获取策略有效。

本轮判断是**暂不启动新的Step-2模块**。先用唯一结构化约束诊断隔离格式短路；若原严格评分恢复可用后，完整供证仍产生实质答案/阶段错误，才有理由提出一次同信息、同总预算、生成前冻结的隐式/显式执行对照。不能把一次额外规划调用或更多输出token免费加给新条件，也不能用评价侧原子答案做运行时检查清单。本轮没有实施或申请该新模块。

## 5. 唯一新生成提案：原S36的输出结构约束

原18题BASE/RAW的36份真实输出已全部读回：27条纯围栏、2条围栏外另有thought、7条非JSON，**旧严格裸JSON仍为0/36**。此前去围栏观察中，RAW18/18的值匹配只属于字段诊断；它不是严格任务完成，不能说明引文、主体、日期和未知协议全部正确。缺失字段、不合规引用和评分构念边界仍可能在格式修复后留下实质失败。

## 6. 研究路线决策

|问题|已有实际证据|未验证的主张|当前决策|

最值得优先解决的是**可执行任务契约及其对应的G使用可靠性**。输出结构约束可以隔离一个已观察的机械故障；明确事实答题与自然简短支持各自要求，可以避免把评价构念差异误写成模型失败。继续积累同类RS卡、扩大RAW/Typed/SPAN重复实验或先训练策略，都不能直接解决这些问题。

若SC36在格式有效后显示RAW相对BASE的实质收益，可继续有限的可验证Memory环境；这仍不等于自然支持reward。如果仍有供证后实质错误，按具体错误决定是否提出一次受控Step-2诊断；若问题主要是未要求重述却按穷举评分，应调整**下一独立任务身份**的要求，不回写旧评价。

C1独立验证若不能在保留任务成功的情况下稳定减少资源开销，应停止当前“简单可见规则即可安全省读”的主张，采用保守固定MS作为已测基线。只有新的、预先冻结的任务确实存在读后信息改变下一步资源选择的需要，才值得另行提出序贯实验；没有这类证据就将论文主张收窄到资源价值、可靠使用及静态获取，不强行保留RL结论。这里是研究路线建议，尚非新实验授权。
