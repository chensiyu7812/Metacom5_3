# Event Understanding：真实数据、能力入口与学习边界

本轮实现的是可执行的来源证据检查工具，尚非合格的全自动事件理解模型。它接收实际可见原文和候选命题，不接收gold、必要事实、正确动作或未读来源。`event_understanding.py`提供`inspect()`、`LocalNLIAssistance`和`invoke_from_gsws()`；调用结果保留原文ID、角色、报告日期、精确线索坐标与处理成本。没有自动把词面线索、NLI分数或引用存在变为事实。

## MAVEN-FACT实际版本与用途

论文：[ACL正式版本](https://aclanthology.org/2024.findings-emnlp.651/)，[arXiv v1](https://arxiv.org/html/2407.15352v1)。官方代码[THU-KEG/MAVEN-FACT](https://github.com/THU-KEG/MAVEN-FACT/tree/67544719c60c6eb7587ed00a3e59df83822f6847)固定提交`67544719c60c6eb7587ed00a3e59df83822f6847`；先前本机下载使用作者`lcy2723/MAVEN-FACT`提交`9b1961cc28333e74972b9a48c28357549cb8403e`，两仓身份不混同。数据来自作者README链接的公开训练文件，实际135,513,936字节、SHA256 `190522b44f0702af030161924d7cb94c4a06bd5d6e2b40d79f8f1eaa5886bab7`。

支持词问题中23项为文字/offset不一致，1项offset越界；包括空格差异及词位指向其他词。保留原问题清单，坐标不一致时`coordinate_eligible=false`。有支持词的CT+为44项、Uu为13项；PS+/PS-/CT-中分别260/2/110项没有支持词。不能照论文概述硬编码“非事实类必有、CT+必无”，更不能将空值当事件不成立。

真实入口文件将`INPUTS.private.jsonl`与`TARGETS.private.jsonl`分开。输入仅文档、句子、token及**明确标为官方提供的trigger定位**；事实性、支持词、论元、事件共指与时序关系在监督侧。该条件EFD任务不是生产级端到端事件发现。报告/事件日期、陪伴用户身份、计划/尝试/完成阶段没有被编造为MAVEN原标签。

按固定文档ID哈希将官方train划为2,602文档/66,362提及训练候选与311文档/7,577提及内部开发；50项均衡能力样例为每类10项，先于模型结果固定。它们不是独立官方test，也不支持总体分布性能推断。LongMemEval与fold6未用作训练。

**语义迁移限制**：事实性表达作者对事件成立/可能成立的承诺，包含未来可能发生的事件；CT+不等于“过去已经执行”。计划本身可被确定报告，但计划目标是否完成需另有来源。MAVEN文档作者不是陪伴用户，论元Agent也不默认是user。时序关系有监督价值，用户当前目标、帮助适用性及情绪支持质量需要因果对话材料补充。

## 对话开发材料与实际CPU对比

来源沿用SourceRegistry：4个ESConv train且无EvoEmo重合的家族；EvoEmo历史train owner p5/p6各2个前缀，与GSWS owner/family闭包隔离。按固定family哈希与词面线索选择首12话轮内的真实pre-supporter前缀；没有读未来目标回复来构造输入，未使用ESCA未来窗口标签，fold6排除。p5/p6的原始ESConv会话与其衍生历史按owner分组，不能当独立用户。

32项包括原义支持、否定改变、主体交换、建议→执行、考虑→已换工作、担忧→确定发生和日期过度精确。对话原文是真实来源，**命题对照是本轮构造的开发样本**，不伪称自然产生的错误；参考为助手开发标注，独立真人未审。

先固定输入、参考、阈值，再用既有`cross-encoder/nli-deberta-v3-base` revision `6c749ce3425cd33b46d187e45b92bbf96ee12ec7`进行CPU float32/4线程推理。沿用0.8支持/矛盾门槛、对立类≤0.1，512输入容量，超限拒判而不截断；未训练、未调阈值、未比较新Judge候选。

结果为7/8明确支持被接受、9/9明确矛盾被识别；15个未知中9个保留未知、3个误支持、3个过度判矛盾。3个误支持均是把seeker报告改为supporter报告。明确否定相对可用，主体/未知失败仍在。不能用这32个开发参考证明独立资格，不能由0/8 false-fail忽略1个正例拒判。模型原始概率、输入、参考、逐项错误及成本均私有保留。

程序流程还在16个GSWS观察上执行了相同原文适配，保留793个话轮和543处可定位词面线索。`action_stage/factuality/event_time`没有模型资格时保持unknown；工具不自动填正确答案。此处解决的是专业能力的真实数据入口与调用边界，语义能力尚未解决。

HF连接工具本次返回`Tool model_search not found`；模型元信息改由公开Hub API核实，无私人文本外传。限定检查后不继续无止境搜索候选。

学习候选以MAVEN事实性＋支持词定位为第一辅助头，以训练家族对话的角色、阶段、报告/事件时间、未知及更新为迁移任务。先比较来源定位流程、通用模型和有明确标签身份的专用模型，再决定是否需要SFT/LoRA或多任务学习。已有50项文档开发集和32项对话开发对照可以发现缺陷，但不能同时用于调参与独立确认；最终确认另取来源家族。独立参照与合适专用checkpoint尚不完整，**本轮不提交可直接启动的训练授权，不训练、不复用旧155条弱监督自然回复**。

即使事件能力改善，仍需分别测量自然支持、共享状态和适应性调用；不能把事件分类收益写成陪伴质量或序贯优势。
