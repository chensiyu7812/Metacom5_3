# GSWS：语义理解与自适应陪伴决策，第一阶段

本工作线从 `c7a83bfb21ad4163eae8097945bc365b7ad51811` 独立开始，完成于2026-11-27。它不是GE3，也不是扩大GE2。研究者已经批准调整主线；本次只实施CPU工作，**新模型调用、GPU加载、付费API和训练均为0**。旧结果、PR #28、MIDSTATE4和原220次额度不变。

已交付可执行的“实际来源→解释器→有版本的共享状态→Generator”链路。固定8个目标、每目标两个实际观察状态，共16个状态，A0/A1/A2共48个终局槽和32个解释槽。4个作业的独立准入已通过；实际模型实验仍待批准。[运行申请](GSWS_RUN_REQUEST_ZH.md)、[任务与评价合同](GSWS_TASKS_EVAL_ZH.md)、[复跑说明](GSWS_REPRODUCE_ZH.md)、[迁移清单](GSWS_MIGRATION_ZH.md)、[官方研究与数据核查](GSWS_SOURCES_ZH.md)。

## 研究问题和主张边界

研究对象是实时长期陪伴中的用户目标完成、语义可靠性、适当支持及实际交互延迟。M0+R0、不获取以及充分后停止都是合法行为。token和调用数仅说明机制成本。

| 新研究问题 | 本阶段可回答什么 | 尚不能回答什么 |
|---|---|---|
| RQ1：合法观察能否形成可更新、区分报告/推断/未知的语义状态？ | 在同源两个状态检查人物、阶段、时间、目标及未知的实际模型解释 | 长期全量记忆正确性、独立泛化 |
| RQ2：共享状态是否比RAW和普通阅读笔记更可靠地支持当前目标？ | 16状态三臂配对，区分解释改善、G执行改善与新增误用 | 正式自然支持reward、数字人整体效果 |
| RQ3：可靠语义状态是否改变获取/继续/关闭的价值？ | 本阶段只接上同一状态的PM/G读取接口 | 尚无状态驱动PM行为实验，更无序贯或PPO收益 |
| RQ4：质量与真实时间代价如何共同影响停止？ | 冻结实际本地解释→G计量，保留前态构建成本 | 未运行的GSWS延迟、客户端首文本、Tokkio首段语音 |

候选贡献不是“首次POMDP/RL/动态检索/结构化记忆”。PGMem已有多粒度证据图及更新，Graphiti已有时间有效性，Self-RAG已有检索与支持性反思，ESCA已有状态估计与策略规划。这里值得检验的是：**同一合法观察中，目标条件化、保留不确定及阶段关系的解释，能否作为PM和G共同依赖的状态，并在信息增加时可靠更新**。这是候选机制，尚未证明创新或收益。[逐项差异](GSWS_SOURCES_ZH.md)。

## 已实现的最小机制

长期来源层仍由原SourceRegistry、As-of、Ledger和RAW/SPAN承担。没有把当前问题或答案写入长期历史数据库。在线GSWS只接收当前可见对话与GE2实际`read_intervals`，保留源话轮、说话人、报告时间、字符坐标及原文哈希；未读正文、评价事实、正确动作、basic_info和未来会话没有进入正常输入。

`gsws.py`提供严格输入投影、解释协议、版本父链、共享读取视图和G附加消息；`gsws_runtime.py`执行实际工具、解释、核验、G调用；`gsws_worker.py`复用GE2的HF、被动首文字计量与进程守卫；`gsws_run.py`实施独立SHA准入和预算。没有修改旧GE2执行器。

A2包含当前目标与边界、带来源的理解项、主体/阶段/事件时间/适用性、未知与冲突、回复含义。事实性仅表示“来源报告了什么”，不自动等同客观真实。实际动作及时间条件由宿主提供，模型不能用自报状态授权动作。A1同样允许记录角色、否定、阶段、未知和修正先前笔记，以避免把弱笔记基线制造为对照。

S0只看当前对话；S1在同一目标下执行原query的BM25 Top4及全部返回父会话EXPAND，五次原语操作、同一4096 source-token容量。此处不是Direct选择，检索未使用评价坐标。A1和A2都携带各自**实际上一次解释输出**，A0获得相同全部原文。此前终局回复不假装为用户真实对话，不进入S1。版本链更新的是当前解释，不把最新意见直接升级为真相。

原文和坐标完整侧车在本机；模型不需要每句话重复读数个长哈希。第一次CPU检查因此发现并修复了不必要的上下文膨胀。最终不删原文，解释输入的CPU样例范围675–8427 tokens，G的RAW输入145–4259 tokens。真实解释输出长度、延迟和语义仍未知。

三臂均增加同一来源范围说明；G原系统提示、模型及终局decode不变。新结果不能与旧GE2条件当作同一payload合并。A2的来源ID可沿侧车回到实际观察；G看到完整同源RAW和未验证解释，引用ID合法不会把该解释升级为事实。

## 已取得的证据

- 16个实际状态已构建，源文件、前缀、检索返回、原文坐标、输入token及评价侧车全部落盘。合计核查793次可见话轮坐标；有配对重复，不是793个独立样本。
- S1八个目标均读取4个来源，原检索+展开5次，没有容量拒绝。本批不能宣称覆盖了所有稀缺信息场景。
- 必要引用组的供应变化：Q01 0→2/2，Q03 1→2/2，Q05 0→2/2；Q04当前已经2/2。Q06两个状态均保留未知。Q02/Q07/Q08不要求历史复述。**Q01精确日历解释仍有争议，引用组2/2不说明日期语义成立。**
- 原生tokenizer、实际来源工具、父版本和三臂等源断言已跑通全部80个**模拟后端**调用槽；真实模型调用为0。真实worker拒绝把CPU fixture当模型输出。
- 11项针对来源/协议/预算/版本的测试通过。语法mask与冻结decode在两条合成有效路径通过，最少仍有2个有限候选；全非有限logits被拒绝。这不是对任意模型logits都能完成的证明，也不证明理解。
- ESCA官方窗口的CPU反例：合成8个seeker/8个supporter，用原函数4/2窗口得到12个目标—上下文组合，12个都能看到目标后支持者，9个还看到后续seeker。不能将其原离线标签直接当实时因果监督。
- MAVEN-FACT官方训练文件已下载，73,939个事件提及中CT+占94.38%。许可仍未明确，不开始训练；高多数类准确率不是语义能力证明。

## 下一阶段的有限决策

先执行本次固定三臂，不再按胜负换题、延长摘要或试提示直到出现正结果。以目标/来源家族分组，报告修复、保持、退步和未知，不能把16个相关状态当16个独立来源。

若A2在明确来源支持的主体、阶段或未知处理上有可复核修复，且不是单靠更多计算或普通笔记解释，才准备独立来源验证。任何修复同时必须报告新增错用和真实时间开销。若A1解释全部收益，停止“专门共享状态结构有独立增益”的主张，可保留普通阅读作为工程选择。若较强G直接读同样RAW解释全部收益，转向Generator能力与成本研究。较强G参照仍是独立、未准入方案，缺少它时不能排除模型能力解释。

若出现稳定、可核验的语义缺陷，后续优先研究公开监督和训练来源上的参数高效语义适配：主体归属、事件事实性/行动阶段、报告与事件时间、来源不足、增量更新。MAVEN需先明确许可；ESCA需因果前缀重标和来源家族映射。教师只看训练来源，不看评测目标；训练/开发校准和独立确认分开。旧155条弱监督自然回复不再直接用于新Generator训练。

只有同信息下共享状态有可靠收益，才推进“有/无共享状态×固定/自适应决策”2×2。若强静态解释全部决策收益，停止当前序贯优越性和PPO路线；这不否定更完整长期陪伴POMDP，只说明该动作域没有证据支持训练优势。自然支持评价仍不具备训练资格时，不训练该reward，也不阻止明确语义任务的监督学习。

目前解决的是合法输入、共同信息条件、可追溯状态版本和可执行对照。**仍未解决的是解释是否正确、G是否恰当使用、状态是否改善决策，以及独立自然支持评价。**这些问题现在成为被检验的研究对象，而非默认前提。
