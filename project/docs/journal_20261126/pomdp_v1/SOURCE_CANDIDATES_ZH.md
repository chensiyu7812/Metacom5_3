# 真实来源候选与 SEARCH/EXPAND 读回

工作线 B 已固定 **8 个来源情境、16 个当前目标**，完成原 80 条 CPU 路径及追加 16 条完整 Top4 压力读回。没有调用生成器、控制器模型、GPU 或收费 API。这些结果展示了真实来源、可见线索、查询依赖和后续展开如何相连；没有测得最终回复收益，也不能据透明规则的表现否定完整 POMDP 的可能性。

每个情境分别有事实目标与自然支持目标。来源是 3 个既有开发家族，复用隔离缓存的 91 个完整会话；实际各目标保留 11–26 个合法候选，共涉及 54 个不同历史会话。原 family closure、split、PrefixSpec、报告时间和 ready-at 保留；没有读取封存 fold6 正文，没有为增加序贯优势删去来源或制造矛盾。资料与作者均有历史开发暴露，不能称未见来源或独立确认集。本线未查看本轮 SMV 生成结果。

候选包含四个分散事实情境、一个真实报告更新情境、两个执行/身份未决边界，以及一个当前信息完整对照。实际相邻问答保留说话人和跨度：短答需要前文才能解释时，不把单个片段自动当作充分支持。计划、尝试、报告的体验和当前有效性分别记录；更早与更晚提到相似活动，不足以证明是同一次事件。

人工来源位置与线索假设仅在私有 EvalSpec 中，用于冻结参考和事后核对。工程读口只使用当前可见目标、完整合法候选池及此前确实交付的文字。每次 SEARCH 返回最多两个完整原文话轮及句柄；EXPAND 只能读取本 episode 已出现句柄的完整父会话。原 80 路保持最多 4 次获取、4,096 交付 tokens、16,384 上下文与 320 输出预留；重复访问仍计费。后续查询的每个词都回溯到初始目标或此前实际交付的内容，另将正文词与报告头等元数据词区分。

分母 16 是 8 个事实目标的必要来源呈现槽位；自然支持列是对应的 **可选**来源诊断槽位，不是必答要求。它们跨目标复用来源，不能当作 16 个独立家族或独立样本。所有自然支持目标均允许合适的一般性回应，因此缺少这些可选槽位不等于任务失败。合理拒答与正确处理未知也不由来源匹配自动判定，`task_success` 和 `formal_reward` 均为空。

最后一行只与原路径共享交付 token 和上下文上限：每目标为一次检索加四个整会话读取，共 **5 次原语**，不属于原 4 次原语域，也不交付或收费原 SEARCH 的 snippets。16/16 都能放下完整四会话，最大交付 3,334 tokens、最大输入 3,977 tokens。它显示宽检索可以解释部分供证增量，不能作为同动作、同费用定义下的政策效应。原 80 路、参考与选择全部保留，未因这个结果调整序贯规则。

透明 OneShot 是生成前写定的简单 CPU 程序，不是同 LLM 的强 OneShotPlanning 基线。SequentialRule 使用固定、粗糙的可见词提取规则：16 条改写都加入了已读正文词，也都混入了元数据词。它没有进行语义理解或学习；这些计数不表示 16 次有用的语义线索利用。原规则与无文本控制在部分路径相同，既不能据此证明读后内容无价值，也不能凭较弱程序的差异宣称完整序贯优势。

所有 80 路查询来源和原文跨度核对通过，完整合法池未被缩减。原定义的上下文组新增覆盖来自完整展开；本次第二次 SEARCH 本身没有直接补齐新的已知事实组，但它可以改变随后允许展开的句柄。部分自然支持路径出现可选来源增量，另有事实路径退化；二者均按原参考保留。完整私有观察来自同一助手事后核对，不是独立人类评价。

未来最小生成候选在读取这些 CPU 结果前已按来源类型冻结：P08 当前充分、P06 执行未知、P05 真实更新，分散事实组内按 `SHA256(case_id)` 最小选 P02；四情境双目标共 8 个目标。既不简单取前四，也不按检索胜负更换。此选择不授予 GPU 或模型调用权限，完整 16 个 CPU 目标均保留。具体新生成预算与准入见独立工程提案。

源码提供任务冻结、原 80 路事后源审计和追加 Top4 事后源审计三个入口。18 项测试通过，覆盖源闭包与完整池、真实前缀/角色/跨度、运行输入与参考隔离、源层分层选择、当前足够控制、查询词来源、指代上下文、未知不因匹配晋级、以及不同原语预算不冒充同域对照。首次草稿的一处来源指针在检索前经完整原文复核纠正并另存版本；任务与来源池未变。工程首个未完成 CPU 重放的查询分词错误及随后仅修复合法词检查的重放也保留，没有按供证结果调词或换题。
