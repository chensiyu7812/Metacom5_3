第1作业实际75.819秒，加载父进程区间46.037秒；模型内部首文字、本地Agent首文字和完整回复均**未测得**。这是一次真实启动的成本，不是成功回复的延迟。日志中`MODEL_CALL_START`与`MODEL_CALL_RETURNED`都为0；内部预算对象虽已尝试保留首槽，尚未调用backend.generate。48槽中12槽为作业停止后未执行，36槽属于未启动作业。[原始日志复算](gsws_actual_v1/ACTUAL_PUBLIC.json)、[48槽状态](gsws_actual_v1/SLOT_STATUS_PUBLIC.jsonl)。

根因明确：`gsws_runtime.call()`先捕获start；`EXPERIMENT_GUARD`没有传stamp，正式日志器采集了更晚时间；随后`MODEL_CALL_START`传回较早start，触发`journal clock moved backwards`。这是运行代码缺陷，不是机器时钟、模型语义或GPU性能问题。原CPU替身只list.append，未调用正式MonotonicJournal，因此漏检。

已在独立候选中修复为`EXPERIMENT_GUARD(stamp=start)`，不删除时序检查。使用正式日志器、真实来源和原生tokenizer完成全部80个替身调用，另有12项GSWS及4项能力工具测试通过。模拟仍没有覆盖真实模型生成；测试通过不是语义假设成立。

修复超出原批准的“仅输入修订”，且第1次加载已经耗用，不能偷偷重建scope后沿用批准。**一次技术恢复申请已具体冻结，尚待批准**：[申请与四份SHA](GSWS_CLOCKFIX_RUN_REQUEST_ZH.md)。新包不会解除原scope、覆盖旧记录或改变题目。批准后上限仍为80个尚未发生的模型调用，但需要新4次加载，连同失败启动累计最多5次。当前没有自动续跑。

## 已取得的新语义能力证据

**Event Understanding是本轮第一项能力候选，依据仍是历史主体/阶段错误及本轮CPU实测，不能称为由不存在的GSWS新输出选出。** 它由原文坐标工具、角色/时间保留、事件检查流程和可选现有NLI组成，不是换一个Prompt名称。所有工具结果仍是候选，不能自动写入MP/ME或变成reward。

已将MAVEN-FACT官方train实际处理为73,939个输入及独立监督目标，覆盖2,913文档；文档级划分为2,602训练候选文档和311内部开发文档，不碰官方测试。触发词73,939/73,939、论元字符跨度326,257/326,257、时间表达16,688/16,688以及792,445条时序关系端点均可机械定位。支持词有24项坐标问题（23不匹配、1越界），保留原值并隔离相应证据监督；CT+/Uu及非事实类的空支持词不自动变成负例。[数据入口与适用性](EVENT_UNDERSTANDING_ZH.md)。

在4个ESConv训练家族及2个EvoEmo训练owner的8个真实因果前缀上，先冻结32个构造语义对照及助手开发参考，再运行既有NLI（CPU、一次加载、无训练、无调阈值）。这是能力开发诊断，不是自然支持Judge资格测试：

相对这些开发参考，false-pass为3/24，false-fail为0/8，但另有1个正例拒判；unknown输出10/32。3个false-pass都是主体交换，3个unknown被过度判否。参考由本助手编写，32项来自8前缀/6 owner或来源组，不能当32个独立确认样本。既有NLI仍不能独立承担角色归属或未知判断，原阈值没有因结果调整。

## 研究决策

1. 首先完成同题GSWS实验；此次技术失败不能支持或否定A2、语义工作记忆、POMDP或轻量PM的科学主张。唯一当前可执行的新GPU申请是技术恢复，不增同类任务。
2. 不把NLI升级为主体裁判。事件技能优先研究来源角色、计划事实与执行事实的分离、未知保留及读后更新。已有32项是开发暴露材料，后续独立对话验证需来自不同训练/验证家族，不将其同时用于调参和确认。
3. 共同状态结构的独立收益、普通笔记竞争解释及更强G竞争解释均未解决。若Notes解释收益，收窄专门表示主张，不否定工作记忆逻辑架构；若能力提升不能形成反馈可靠的决策差异，不开始BC/PPO。
4. 保留自然支持外部评价。事件分类或结构化QA不能替代长期陪伴质量；完整Writer、跨轮Agent经验进化、Tokkio语音计量仍是后续工作。
