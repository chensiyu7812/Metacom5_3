# GE2：一次机制修订、真实供证结果与有限生成申请

起点：`48fdb54a683b51c9d5f77c98784a7b4f68b66d35`。本轮新增真实模型调用、GPU作业、付费API和训练均为0。原53次DR调用及其评价、MIDSTATE4 package-v4、静态选择负结果、PR #28和剩余220次额度保持。GE2的新代码与包不覆盖旧执行器，也不使旧DR3自动续跑。

**本轮已落实GE2共享环境、检索、动态执行及冻结运行包。实际来源检查找到了首读后充分、继续后补足以及合法记录仍无法确认的不同状态；但强静态读取也覆盖了大部分可定位证据，尚未证明读后策略有独立质量或延迟收益。** 当前值得做一次有限比较，不具备立即训练自然支持reward或宣称序贯优势的依据。

研究目标仍是实时长期陪伴数字人的用户目标完成、回复质量、可靠性、适当获取与停止、实际交互等待。M0+R0是合法成功路径；token、调用次数和命中率不代替这些结果。

## 2. 实现的具体变化

复用原SourceRegistry、As-of、Ledger、SnapshotPrefixPort、ReadingView、native tokenizer、Generator renderer、HF生成与GPU守卫。新模块集中在 `journal/ge2_*.py`，一个运行链路同时支撑R（检索）、U（使用）和D（决策）归因，没有三套Agent或数据库。

|已实现变化|新合同|实际核查与边界|
|---|---|---|
|语义query改写|移除逐词白名单；保留纯文本类型/长度、真实可见输入、owner/时间/句柄隔离|新词可合法查询；查询词不进入最终事实正文，不被当作已确认个人事实|
|上下文原文单元|每次SEARCH最多4个不同父会话，每个最佳锚点固定±1原话轮；角色、报告日期、原turn编号保留|问句有相邻上下文，不将问句或建议自动升级为行动；没有语义抽取晋级|
|可变粒度与已读状态|SEARCH可排除完全读过的候选窗口；EXPAND可取相邻一轮或完整父文；句柄版本明确|旧handle仍指向原anchor，新handle记录新范围；不删静态方法可用来源|
|去重与时间组织|最终原文按来源日期/rank/turn排序，同父文按原文区间并集呈现|重读仍消耗访问与真实工作；4096是去重后的源正文容量，累计物化token另记|
|状态与观察身份|完整content hash绑定last_hits、句柄顺序/版本、已读区间、行动史、预算、拒绝和截止时间；snapshot绑定完整实际观察和采样时钟|修复旧同hash异observation反例；自然时间流逝不误判成内容并发修改。控制器预算补入后重新绑定snapshot|
|目标与实际时间|观察含原完整可见对话、公开时间、已读正文、允许动作、真实elapsed和remaining-time|目标目前是可见文本，非校准语义抽取；剩余时间取单路径600秒与作业真实剩余时间的较小值，预留300秒终局。不是数字人体验SLA|
|请求级协议失败隔离|坏JSON、状态非法动作或控制器length结束该获取路径，最多使用一次原已预算终局fallback|保留降级记录，不重试、不增加终局调用；来源/身份/设备/worker故障与作业超时仍停整包。fallback回复质量待评，不自动算可靠成功|

控制器用同模型、同静态语法约束和总768输出token预算。OneShot一次提交最多5个获取动作的程序；ToolAgent最多5次逐步控制调用。5次获取后已无继续动作，程序强制STOP并标明原因，不再花一次模型调用“选择”唯一动作。控制器自报的充分/不足/不适用/无法确认/未评估只作观察，不是任务成功或reward。

真实native tokenizer和xgrammar的有限CPU回放通过，完整真实来源的37个终局槽通过CPU传输fixture；这些回复明确标为非模型文本。有限语法路径不能保证所有模型logits均有合法交集，运行时仍对空finite交集失败关闭，不解mask、不改decode救回。

## 3. 实际检索结果与数据条件

完整分母为原16个开发构造任务加原30个官方QA，共46题；额外冻结8题运行清单，其中3个官方QA与原30重合，另有3个真实prefix和2个旧SMV联合任务。108行是54个任务呈现×2个检索器，不是108独立样本。全部来自已经暴露的合法开发来源，未读取封存测试正文。

共享BM25在新ranking前固定为主运行配置：k1=1.2、b=.75、Top4、固定±1窗口、完整父会话源文索引、所有原角色、无包装词。Time-Lexical-GE2是同池、同返回量、同窗口的CPU比较；旧RET/Time-Lexical/Hybrid身份不改。没有依据新生成胜负选题或调参。

原“首次完整供证0/7”不再是所有新读取条件的共同事实，但**单个最高排名窗口仍为0/7**。不能把更大的返回量全部归因于BM25，更不能把来源齐全升级为回答正确。两种新检索器的排序和窗口锚点一起变化；本比较不单独识别父会话排序的贡献。全部合法池的可定位覆盖更高，但在本批均超过4096源容量，不是可执行的免费基线。

新清单确有当前充分G08、首读充分G01/G02、首读仍缺历史而父文补足G07，以及缺正向事实证据的G03。G02还保留calendar-derived参考假设。G04/G05/G06使用原3/1/3轮pre-supporter前缀，不附加旧构造query的支持要求；自然支持无需强制复述历史。详见[逐题来源表与适用性](ge2_v1/RETRIEVAL_AND_TASK_FIT_ZH.md)。

协调者发现准备期旧供证表漏计“既在历史、又逐字出现在当前请求”的事实，已保留旧准备产物并用固定最终来源重算：G07当前1/2、G08当前2/2。任务、检索配置、排名与旧模型结果均未因此改变。

## 5. 一次有限生成比较与收口

[固定运行申请](GE2_RUN_REQUEST_ZH.md)只含8题×4普通臂，以及5个事实/联合题的DirectEvidence：37个终局，最多85次真实调用，4次加载、0 warmup、0 retry、4×1200秒硬限。任务、来源、评价和共享配置均已固定。普通四臂是STOP、FixedTop4、同域LLMOneShot和LLMToolAgent；Direct源定位只用于使用能力诊断，不进入普通策略。

若强静态/OneShot解释全部真实收益，停止这一版本的序贯优越性主张，不再扩同类样本或换提示词追正结果。若ToolAgent出现质量或实际本地时间增量且没有预定可靠性退步，仍须区分完整配对、技术缺失、参考争议和来源组，再考虑独立验证；这8题不能确认总体效应。没有中间STOP/继续的实际反事实端点，就不编造正确动作标签。

若Direct充分供证后仍出现明确可复核的目标执行错误，只保留已有一次同资源、同G、同调用/320总输出/墙钟预算的隐式与简短显式操作计划对照；本轮不实现、不申请该额外调用。若无法修复或增加错误/等待，停止该改进。所有原自然支持外部验证仍保留。

**学习判断：**实际可程序核验的结构化任务已有有限反馈；GE2自由回复仍需要分项证据审阅，不能直接用来源覆盖或controller自报状态训练。当前已找到值得验证的读后条件空间，但尚未证明值得训练轻量PM。用户目标、源可用性与时间代价之间的关系继续研究，不能由这套小池实验判决完整长期陪伴POMDP。

未来日常提醒和计划更新可另立功能任务：以明确授权的创建/取消结果、时间与时区、版本更新和未知状态作为可程序核验结果，同时单独保留支持质量。它们需要独立动作/数据/授权身份；本轮没有扩成完整功能Agent。
