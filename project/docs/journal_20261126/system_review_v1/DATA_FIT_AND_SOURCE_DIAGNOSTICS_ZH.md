# 数据用途适配与实际来源诊断

本次仅复查既有、已经暴露的开发材料：8 个来源情境、事实/自然支持各 8 个构造目标、3 个 owner-family 连通组；16 个合法池共涉及 54 个不同历史会话。没有扩大样本、读取封存 fold6 正文、删减静态候选、改变原评价或调用模型。原 8 个动态目标属于其中 4 个情境、2 个家族。来源足以构造受控的信息与阶段边界，但本批不能代表独立人群，也不能据固定规则失败否定完整 POMDP。

## 2. 原始前缀合法，不等于运行目标原生

CPU 逐条核验的 16 个锚点全部满足末轮为 seeker、下一轮为 supporter。按两种目标重复计，原前缀有 10 个一轮、2 个两轮、4 个三轮；运行输入则全部只有一条构造 query。**16/16 query 与原前缀末句不同**。原始前缀只控制 owner、时间、ready-at 和候选合法性，并没有作为完整可见对话进入本批任务。

这些构造目标使检索需求、禁止断言和比较目标更明确，也改变了 query 的词分布及当前支持需求。P08 将实际当前来源摘句放入目标；其余目标提出额外的历史查询或支持操作。不能把因此出现的“需历史”自动归属于原开场话语，更不能把原始 supporter 回复当作这些新目标的标准答案。

这不是否定构造任务：它们适于检验可见目标与资源使用的受控关系。它限制的是外推。下一阶段若检验原生自然支持，应另立身份、保留实际完整 pre-supporter 前缀，并依据可见上下文确定支持目标；不能在本轮把旧 query 替换成原前缀后继续沿用同一结果或假定历史必需。

## 4. Time-Lexical：真实贡献，不按名称归因

实际排序为 `|query词集合 ∩ reading_text词集合| / |query词集合|`，同分依报告 rank 再依 record ID；单片段选择在所有角色原话中最大化 query 词交集，同分取最早话轮。没有 BM25/IDF、阶段判断或问句排除。本次动态工厂实际使用 Time-Lexical；存在 Hybrid 接口不代表已运行 Hybrid。

CPU 复算保持全部合法候选，并逐次验证原 Top2 与旧 trace 相同。所有新评分诊断在解析 EvalSpec 评价字段前完成（此前可核文件哈希）；固定词表没有依据覆盖率调参。这里“功能词”是该诊断表的简称，也包含常用问句/指令词，并非独立标注的纯词性类别。下列删除词或只看单方角色均为**分数敏感性检查**，没有改动实际资源、策略或生成输入，也未证明任何新检索方法更好。

|口径|查询数 / Top2 片段呈现|supporter 片段 / 其中问句|匹配词位 / 其中固定功能词|去包装的 Top2 变化|去功能词的 Top2 变化|仅 seeker 原话的 Top2 变化|
|---|---:|---:|---:|---:|---:|---:|
|16 个原构造 full-query 首检|16 / 32|11 / 9|563 / 407|0/16|10/16|14/16|
|原 CPU 规则的后续检索|16 / 32|12 / 10|733 / 425|0/16|8/16|13/16|
|动态运行中实际 LLM 首检|4 / 8|4 / 4|20 / 0|0/4|0/4|2/4|

词位是 query–候选交集的呈现计数，不是独立词或独立样本；角色贡献与功能词分类可能重叠，不能相加。第三行仅涉及两个事实目标、两臂的实际首检；不能与第一行 32 片段混为同一分母。

包装独有词在前两行各仅贡献 2 个 Top2 匹配词位。16 条规则改写确实均混入已读元数据词，但这些**新加元数据词对该合法池的匹配贡献为 0，去掉它们也没有改变 Top2**。它们占查询空间、反映提词规则粗糙；本证据不支持把它们说成排名失败的主因。功能词敏感性较强，但动态短查询已没有功能词匹配，仍可能只读到支持者问句，所以仅加停用词表不能解释或修复所有失败。

支持者问句不是应从库里删除的“坏数据”：原短答可能正需要该问句确定对象。实际 T03 两学习型臂只取得提问，没有取得用户回答，原完整必需组为 0/2；Top4/Rule/NoText 是 1/2。应分别检查检索与展开、片段角色/阶段使用及最终回复，而不是将全部遗漏写成完整供证下的 G 失败。允许模型看到完整问答是待测的机制修正，不是本轮已证明的收益。

## 5. 有限旧个案读回与 Step-2 边界

仅按主代理要求复核既有 SMV30 的 T15/MS（`smtask:17b803bf1d62ba051178d632`）：原请求、输出、评价身份一致，两项必需来源均在实际输入，原回复漏掉所问的早期行动阶段，转而比较心理负担与缓解。原未完成标签和额外断言不确定均不改。这支持“完整供证下目标应用/表达仍可能失败”的有限诊断，不识别 G 的内部理解原因，也不能证明训练或 Step-2 必然有效。T03 的缺源不能混入这一证据。

本轮没有新增 Judge、重新评分或扩大人工审阅规模。若后续提出小规模 Step-2，应限定为可复核的角色、阶段与当前操作执行问题，并另留完整供证失败与检索缺失两个分层；先证明机械/可见任务合同改善，再讨论自然支持质量。旧未知不转成确定标签，既有待真人事项不因 CPU 检查而晋级。
