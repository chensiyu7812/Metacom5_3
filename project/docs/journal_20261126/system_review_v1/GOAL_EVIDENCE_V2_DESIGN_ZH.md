# 目标与证据条件化的获取：一次独立新版本提案

提案身份：`pmrl1-j-goal-evidence-adaptive-v2`（GE2，**设计态，未实施、未授权模型运行**）。起点为 `c40b90c99cb991cf1c2793ffbe9927a0011885ab`。它不替换原 FiniteHead、DR1–DR4 或其评价，也不重新开放旧220次。此次唯一可申请的小实验另见 `MIDSTATE4_RUN_REQUEST_ZH.md`，使用旧资源与动作语义，不能据此宣称GE2已经验证。

## 1. 研究对象与可证伪主张

目标是实时长期陪伴Agent：用户状态与当前需求不同，合适行为可能是不获取、回忆某个事实、查清计划阶段、采用一种支持方法或明确无法确认。主要结果是目标完成、回复质量、可靠性、获取及停止适当性、实际交互等待；tokens只是机制指标。当前能做的是单次真实前缀中的信息获取，仍无真实用户动作后状态转移数据。长期陪伴是研究目标，不能由历史重放直接验证长期支持效果。

GE2只检验一个机制主张：**在同初始目标、合法来源与预算下，实际读到的信息能否改变下一次获取的参数、粒度或停止决定，并改善终局目标或降低实测等待且不增加预定错误。** 改写query、命中更多原子、调用更多工具、写出SupportPlan都不是成功条件。若目标条件化OneShot或强固定读取已经解释收益，收缩为资源组织/检索工程，不归因于序贯策略。

首次使用POMDP、动态检索、结构化记忆或RL均不作为创新主张。既有[文献审查](../pomdp_v1/RELATED_WORK_AND_NOVELTY_ZH.md)保留；本轮没有新增文献优先权结论。潜在贡献须落到可辨别的任务条件、因果对照和实际质量—可靠性—等待证据。

## 2. 明确保留的底座

复用SourceRegistry的来源身份与隔离、原Prefix/As-of/Ledger、RAW/SPAN及原文定位、固定Generator与native tokenizer。MS-SUM只用于导航，读出结果必须能回到原文。Time-Lexical保留旧身份作工程基线，Hybrid保留竞争候选；不在看过答案后修改二者参数。MP/ME继续pending/mask，当前不扩充RS卡片。

底层来源表示统一；视图可以不同，但不复制一个新的个人数据库。数据准备、检索运行和评价分别拥有权限：检索器只拿合法池和可见请求，评价端才读必要事实/引用位置。owner/family可以由可信服务用于隔离，不能序列化成策略特征。

## 4. State、Observation与belief的严格区分

环境内部状态保存来源版本/合法池、Prefix身份、工具索引、全部访问记录和已读区间。策略只获得：真实可见对话前缀、当前公开时间、用户目标文本及其未校准提取、已读证据和source-local句柄、查询/动作历史、合法候选类型/读取粒度、预算与实际elapsed。source-local句柄不编码家族/答案。

状态身份至少绑定：episode与来源/模型/renderer/检索版本、可见前缀、所有已读区间、handle版本与顺序、last_hits、已展开范围、允许动作及其参数、token/调用/时间预算、拒绝状态和结束原因。时间会变化，必须区分不可变内容身份与带单调时间采样的决策快照身份，不能用过期快照默默执行新动作。

四种证据状态是策略的可检查判断，不是评价端标签：

- **充分**：对于当前明确目标，已读内容足够作答或支持，不必穷尽所有相关历史。
- **不足**：存在与当前目标相关的具体缺口，并有合法候选可能补充；返回行动意图而非正确答案。
- **不适用**：虽相关，但属于其他主体、旧阶段、假设/建议、用户已否决的方法，或当前目标无需提及。
- **无法确认**：合法记录没有确认事件、真假仍冲突或已无可达证据；可停止并表达范围内未知。

同一记录可对事实查询不足、对简短支持已充分；支持回复可以隐式利用历史或完全不提。不能把“存在相关资源”写成“必须获取”，也不能把“历史没有记录”写成事件没有发生。该状态不是心理诊断或概率后验。

## 5. 同信息、同动作域、同预算的比较

在任何GE2生成前统一冻结原文库、时间过滤、索引、窗口/父文读取、去重规则、完整G渲染、语义query规则、总调用/资源token/墙钟预算及停止合同。当前只设计，不分配新的GPU额度。

|条件|观察和决定|公平性要求|
|---|---|---|
|STOP|当前可见前缀直接回复|永远合法；成功不要求资源采用|
|Fixed Top-k / Top4|同初始query，同索引，固定k与粒度|完整读取操作暴露给所有方法；若Top4需1检索+4父文，则全部方法共同K=5或全部采用另一明确共同预算。不得将旧K=4 vs5叫等动作实验；旧Top4仍另列实践参照|
|目标条件化LLM OneShot|同一模型从初始观察承诺程序，可引用未来返回的rank handle|同工具、同query语言、同完整证据及预算；没有读后正文反馈，但不人为阉割其一次性语义改写|
|普通LLM Tool Agent|同模型每步读实际观察后选工具/参数/STOP|所有规划调用时间和输出计入；终局G保持相同。不能免费增加控制次数|
|Sequential Rule|预冻结透明规则，使用可见目标和实际新证据|先报告其适用范围，固定步数不等同充分性判断；不得用任务ID或人工引用定位|
|同控制器NoText|相同控制器/工具/参数/预算，只去掉读后正文|保持已读身份、budget与动作史；同时记录屏蔽导致的输入长度差异。若做长度匹配需新、预冻结中性替代，不能称严格无混杂。旧透明NoText不改名为此消融|

静态方法可看到的来源池不删减；序贯方法也不能从人工定位直接获得额外候选。把改写能力、证据窗口、去重和序贯条件化的效果分开：新v2各策略共享组织改变；只有相同v2环境内部的OneShot/ToolAgent差异可讨论读后条件价值。不能用v2对旧v1的总改进全部归功于序贯学习。

共享资源预算与规划预算都需报实际消耗，统一上限不保证相同实际使用。质量实验允许精确payload复用时只复用质量证据；实时路径不得借缓存命中宣称加速。所有失败和因预算拒绝而停止的路径保留，不把它们与模型主动STOP混合。

## 6. 何时考虑显式Step-2

旧SMV30的T15/MS存在必要来源已供应、却未表达所问早期行动阶段的实际案例；本轮限定读回确认原观察与实际输入一致。它支持“目标执行需要诊断”，**不能证明G内部不理解，也不能证明增加规划有效**。DR T03则混有证据缺失与把问句升级为习惯，不能作为完整供证失败的统一例证。

因此保留一个有条件的独立对照提案，不在GE2主比较中同时改G，也不新增本轮申请：同一冻结资源、同一任务与G下，对比隐式直接回复与**单调用内先给简短操作计划、再回复**。计划只列目标、证据适用/不适用/未知和拟采用的回应操作，不要求详细思维过程，不输入gold、正确阶段或参考答案。两臂各一次G、相同decode及320个总新token上限、相同调用硬限；显式计划消耗同一个320上限，不额外赠送回答预算。仅显式条件改变任务输出合同，作为独立身份冻结；评价只针对最终回复，同时计入计划生成的全部延迟和技术不完整。这个对照检验显式操作计划是否值得其固定预算内开销，不能隔离所有格式/位置效应，也不是已实施的新模块。

只有持续存在完整供证的目标执行错误、且原范围/引用契约已区分后，才准备这一次诊断。不重复六句摘要，不训练新G；若显式计划不修复完整目标或引入新的个人事实/明显等待，则停止该改进，不不断更换提示词寻找正结果。

## 7. 有限推进与停止分支

1. **本轮完成审查和原两个状态的CPU恢复**。冻结最多4次独立分支申请；没有新批准就没有模型调用。
2. **批准后检验原T01/T03的具体rank1展开**。按完整任务、事实错误、阶段/角色、合理未知和从同一决策点开始的时间评价。不因rank2的供证更好就改选或补跑。负结果只否定该动作在该状态的收益，不否定所有合法后续查询。
3. **GE2先通过真实开发来源的条件空间检查**。需要至少存在合法候选带来与当前目标有关的新信息，以及读前充分/读后充分/仍不足/无法确认的可解释状态；完整任务标签仍须独立确认。若现池缺某类，就明确缺，不人为删源或造矛盾。另冻结原pre-supporter自然通道；构造query通道保留开发身份。封存测试正文继续关闭。
4. **只进行一次有根因的新版本比较**。先检验目标条件化OneShot、强固定策略与普通ToolAgent；若新版本组织改善但序贯仍无增量，收缩为组织/检索与使用可靠性研究，不连续重置失败标准。
5. **有可辨别的条件价值后才研究轻量PM**。要求决策时可见信号与合格任务结果，而非事后最快端点、命中率或未知填零；先透明策略/监督选择，随后是否BC、价值学习、PPO另作决策。本轮全部不启动。

本方案不要求暂停全部研究等待一个万能Judge；确定事实/程序边界先用可执行通道，自然支持保留范围明确的语义审阅与原五项真人复核。没有真实用户转移和客户端测量之前，始终收窄长期效益及数字人延迟主张。
