## 新证据改变了什么

### 1. 不能再由“4个结果字段”推断原历史没有行动反馈

固定24段里识别了建议17条、意向20条、尝试18条、自报反应18条、未知12条、明确偏好3条。这是88条助手选记的来源观察，类别可能涉及同一事件，不是全库计数或需求率。

三处精确对照见[原记录与当前视图](../../../../outputs/pm_rl1/research_preparation_20261115_v1/memory/CURRENT_VIEW_COMPARISONS_PRIVATE.json)：

- `mp::mvu_2a73b2853cdd499d576e2ab5`：原话报告已经挂过电话且朋友容易生气；概括却写成避免挂断。引用存在不能抵消概括的语义偏移，也不能反推G必然采用了错误概括。
- `mp::mvu_785a6f6f9e719c52ef13fc57`：引用包含写作工作坊有所帮助、冒名顶替感仍出现；概括只保留参加工作坊。需要把事件和主观反应表达清楚，不能把它包装成稳定档案或客观疗效。
- `me::mvu_c8da36ab41b1d4da5464dd8d`：引用中有“知道并非孤身一人有帮助”和线上社群支持；结构字段的 outcome 为空。这不是源文丢失，也不能强归因为某一项社群干预的效果。

由此可执行的修复是精确的陈述/状态修复及候选视图，随后追踪“原文→编译→时点投影→检索→实际G输入→回复”的断点。不能把本次18条自报反应一律声称为18个漏抽。

本轮已将三处问题做成[候选修复sidecar](../../../../outputs/pm_rl1/research_preparation_20261115_v1/memory/CANDIDATE_VIEW_REPAIRS_PRIVATE.json)，[来源与原身份核验通过](../../../../outputs/pm_rl1/research_preparation_20261115_v1/memory/CANDIDATE_REPAIR_VALIDATION.json)。挂电话及工作坊归入历史事件候选；社群支持与“知道不孤单”的反应分开，不建立无依据的因果链接。当前有效性仍unknown，未覆盖旧资源或冒充完成接入。

### 2. 完整案例不是质量保证

逐卡阅读发现，原标 `Reflection of feelings` 的一例主要是在说supporter自己的电影偏好；原标 `Information` 的另一例是保证自己能解决所有问题。还有案例包含未经核验的事实、健康保证及不应由AI照搬的亲身经历；即时反馈并不证明其内容正确。

这批固定样本保留为质量审查和负例资产，不因结果不利而换成12张看似成功的卡。可供进一步适配审核的条目与暂停正向使用的条目已逐卡列出。**当前是12候选、3方法草稿、0已验证资源增益；没有形成可直接推广的专业RS库。**后续应按预定来源质量标准扩大候选并留下全部筛选理由，而非针对目标回复结果挑赢家。

### 3. 检索与父会话回读有真实接口缺口

新有序域的locator仍是词重合；BGE状态编码不能当BGE检索。`GET_MS`当前只读MS排名首项，父文定向优先尚需共享适配器。方案已经明确这两处新增工程，未写成已经上线。

### 4. 独立确认来源尚未补齐

见[确认清单](../../../../outputs/pm_rl1/research_preparation_20261115_v1/versions/CONFIRMATION_READINESS_ZH.md)：EvoEmo旧test为3 owners/48前缀，其中32有明确历史曝光，另16也不能称未暴露；ESC外源173张中历史分配121张confirmatory，但尚未和Claude等开发曝光逐键连接；AnnoMI候选133个示范尚无本准备包的可用导入/分组。

这些是未认证数量，不等于断言所有材料都不可用。ESC角色和AnnoMI方法示范不能补同一人物的纵向记忆。继续开发不受阻；正式英语记忆泛化主张仍需新来源或明确限定为已有构造人物上的组间评估。中文ENPMR另列补充实验，不能悄悄替代英语确认。

## 下一步的收口条件

阶段A完成了版本盘点；逐条复用连接需在新payload固定后执行。阶段B完成了24段来源首审、12案例结构及方法草稿，**尚未完成专业适用性审核、完整抽取召回率、36前缀清单、最终评价协议和独立确认集**。因此没有将B标为全部完成，也没有启动C生成。

下一批任务依次为：

1. 把有依据的记忆表示问题变成新版本候选视图，校验时点、指代与原文支持；保持旧资源身份不变。
2. 完成可用于开发的来源方法与案例适配；需要专业判断的部分独立列出，不冒充已经审核。
3. 固定目标前缀、全部条件与来源排除；绑定G、renderer、盲评、时间及统计协议。
4. 执行一次机制比较；按结果定位修复；然后接共享检索、简单选择器及顺序/RL比较。

这使后续每次实验都能回答一个明确问题，不再以“又跑了一批回复”替代研究进展。完整顺序及验收见[主方案第5节](PLAN_ZH.md#5-按什么顺序推进到研究完成)。
