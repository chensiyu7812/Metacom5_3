## 本次可用工作

- `LocalBackend` 复用原 P2 公共加载器及其冻结模型、适配器、原生结束规则和设备身份；先加载 G，再加载 BGE。离线环境、文件哈希、软件版本、加载次数、固定生成请求和编码批数逐项核对。模型加载与调用保存 CPU 策略 RNG；工程替身只能用于显式 ENGINEERING_ONLY。
- `GenerationWorker` 接入 `ResearchBackend`。生成前 GPU 检查失败保持 WAITING；进入模型后中断保持未决且不重发；结果已完整封印但未发布时可以补完队列入账。技术生成失败不能变成 q/m 或零奖励。缓存优先仍可用，本次探针使用独立队列，以测真实加载和推理。
- 原先私有工程文件中的 GPU 查询解析移入 `local_gpu_guard.py`，显式传入冻结 UUID。保留初次空闲/显存和其他进程排除规则，去掉旧批次权限与等待循环；不停止其他任务、不更换 GPU。驻留后不对自己的模型套用空闲显存门槛。可见进程查询不保证未来不会出现其他作业。
- 固定探针从已有 train 池按 head/prefix 哈希选取四个不同前缀，不看分数或回复质量。逐例重建读取前后观察与 OFF/ON 请求，核对原 P2 请求身份；公开特征只编码当前前缀和已取得正文。读后下一动作的研究价值仍须正式顺序学习比较，此探针不能替代它。
- CPU 合成链实际完成八次替身生成、八次观察编码、队列发布和重复读取。覆盖来源变更、未授权、加载/批次上限、模型中断、结果封印恢复、随机数隔离与非自然结束。测试用的小向量不进入真实数据或奖励。
