## 2. 来源审查解决的具体问题

选择规则为固定哈希排序、owner轮转：短事实候选池51题，时间多引用池41题，分别取20/10。规则是在来源元数据/内容预览后、任何本批G输出前固定；不是对gold盲选。旧65个train短抽取候选还包含私有事件引用等，本轮先收窄为全部引用可见可解析的51题，不把51与65当成同一统计。

原问题原样进入G，只提供题目自身的时间信息。没有把question group、能力标签、参考答案、目标ID或隐含截止时点给检索器/G。QA使用官方完整owner会话档案，与自然对话严格过去前缀是不同任务范围。

11个排除项保留原件和逐题原因：

- **M05日期/答案冲突**：题目从2025年7月问到10月，gold写约17个月；其引用的presentation会话记录在2026年3月。未把错误答案变成奖励，也未偷偷改成3个月继续测。
- **F13居住地随时间变化**：早期自述农村，随后搬去外地工作、再换近家工作，问题没有给时点。
- **F08/F11/F15/F16及M03/M04/M10**：未给当前情境/时间范围、答案不唯一，或引用不足以认证因果起点。排除不表示原benchmark每种语义评分必错，只是不适合本批高置信诊断。
- **F14重复事实家族**：与F04是同一人的同一个姐妹姓名，不重复当独立收益证据。
- **M08时间冲突**：原会话元数据在7月，但原文双方互祝圣诞快乐。保留冲突，不静默选择一个时点为真。

最终14事实题覆盖11 owners；5个语义题单列。来源审查由助手完成，是可检查的开发标注，不称独立人类gold，也不自动批准为RL奖励。

## 3. 对照与实际路径已经固定

每次资源都是完整会话、原角色与原文。C按原引用集合交付，不新增未引用的答案片段；C是诊断参照，不是数学最优上界。R1/R2只使用问题与该owner的完整会话文本计算相似度，不查询答案或gold引用；按分数下降、session ID打破平分，不根据结果挑路径。

D先在非目标候选中按原生tokens匹配相同会话数，再读完整内容确认；两个自动候选在生成前按话题审查调整并保留原记录：M02剔除仍以工作/财务为主的候选，F19改为父母争吵情境。长度差保留，不截正文来凑齐。其他话题可能仍包含同一人物姓名、一般情绪或背景，不能称绝对零信息；例如F02的D提供Michael姓名，可能诱发猜测，但没有性别自述。

真实排序已有信息覆盖上的差异。例如F04的第一段是朋友欠债，第二段才出现姐妹姓名；F20的top-2未取到原目标前任姓名会话。这是来源/排序观察，尚不是模型答对率。反过来，M02的一个会话已经包含所有要求的信息，M07后一段还回顾了之前的成绩；不能把多引用标签解释为必须多次GET。

## 4. 生成前固定的判定，不看输出再改

主判断限14个明确事实题，语义题不混入这个分母。使用预先列明的短答案别名及来源绑定审查；无法匹配的文本先待审查，否定答案中的姓名或并列猜测不会因命中字符串就判正确。开放语义题按既定要点、实体/时间/顺序与错误附加断言分别检查；相当、未测和技术失败均不填PPO奖励。

|判断|事前条件|下一步含义|
|---|---|---|
|资源增量|C完整答案正确率≥80%；C−OFF≥30个百分点；C−D≥20个百分点；C−OFF正差覆盖≥4 owners|通过才认为该限定QA配置值得继续；不通过停止该配置，不换题追正例|
|实际短检索|预先指定R2−OFF≥20个百分点，并保留至少2/3的C−OFF增益|未通过区分为检索路径缺口，不能据此否认资源价值；仍不启动RL|
|下一阶段|前两项通过后，比较强固定/规则/OneShot，并检查读后内容是否真的改变动作|不把QA答对当作顺序策略或PPO优势|

这些是小规模开发的实用门槛，不是统计显著性、总体效应或投稿资格。完整95个条件的技术覆盖是前提；不确定项保留上下界，只有保守界通过才判通过。OFF使用同一事实回答/不足则Unknown规则；如果OFF猜对仍计入答案准确率，不为了夸大资源增益扣掉。

3秒暂定边界没有转换成奖励λ。此次G单次首token/完整生成计时最多是组件观察，未包含Tokkio ASR、排队、网络、TTS和有效语音；CPU BGE也不是未来部署的设备测量。实际净收益及延迟验收仍待，不因低token数宣布通过。
