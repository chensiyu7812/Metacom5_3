## 3. 这次对照具体说明了什么

- **Q01 的偏好成立，但历史内容是否造成改善仍不确定。**C 确实提到了过去频繁争吵；三条结尾都问最担心重现哪些模式。研究者偏好的是语言自然度，不能把真实历史出现直接计为信息收益。
- **Q02 提供了必要的其他话题对照：C 与 D 同样略胜 OFF。**这与“增加上下文改变安慰语气/表达”的解释相容，不能仅凭 C/OFF 正向就归因定向记忆。
- **Q03 正确用到双方曾约定开放沟通，仍没有胜出。**C=OFF，而 D 更受偏好（程度不确定）。这是“用对历史不保证本轮更有帮助”的具体反例，不是说那条历史永远无用。
- **Q05 的旧小收益没有被推翻，但无法区分定向历史与其他话题历史。**新 C/D 相当，旧 C/OFF 略好保留；不把它升级为信息特异收益。
- **Q06 的 C 在提交排序中低于 OFF、D。**C 更长，也带入过往学业压力，但没有落实预先指定的教学质量缺口；研究者更认可 OFF 清晰具体的课程压力提问。程度不确定保留，所以不称实质伤害。Q03 是另一项 C/D 负例，均未藏入均值。
- **Q08 是第二项联合胜出，但 C 没有采用预设的艺术/写作兴趣信息。**它更贴近当前承受压力的感受。因此保留实际帮助偏好，同时不能宣称已经填补历史信息缺口。读到历史可能间接影响语气，当前单次输出无法排除这一点。
- **Q10 中 C=OFF，D 较差。**另一话题输入可以让回复变得过于简单；这支持报告潜在无效/不利读取，而非定向读取必有增益。

生成前已有内容审查：10 条 C 中 3 条明确采用预设目标（Q01/Q03/Q05），1 条采用相关背景（Q06），1 条采用目标以外的旧信息（Q10），5 条没有明确采用预设目标。Q10 将数月前新小狗/变化说成 recent 的时间延续风险继续保留，未确认成事实错误、未剔除，也未因人评相当而洗掉。没有证据表明这轮系统性减少了重复追问、错误指代或历史矛盾；合理询问旧状态是否变化不能直接算错误。

因此，“G 使用资源的能力”和“这一轮可获得的信息增益”仍有交互，不能说二者已经完全拆开，也不能把提供完整定向历史称为 G 已实现完美利用。停止本轮路线的依据是**约定范围内的实用证据不足**，不是已经证明资源的理论价值上限很小。

## 4. 人评给研究留下的有效内容

研究者指出的安慰感、提问自然度和解释负担属于实际帮助性，不是低于“纯 AI 研究合格”的外围指标。尤其用户已经难受时，安慰后立刻要求其规划、解释或猜别人反应，可能削弱前面的支持。Q03、Q06 也表明更贴合处境、具体的追问可以更好，不能归纳成“不要提问”。Q02 的长回复偏好与 Q06 的长回复劣势并存，不能做成“越长越高分”。

Q04/Q05/Q07/Q09 的不同策略均可接受应保留为评价参照，避免裁判强行拉开差距；不能从一位研究者的偏好推断每位历史用户的真实偏好，更不能写入这些历史用户的 MP。文本译文下的感受也不足以确认声音或视频会怎样改变判断。

这批参照的作用是**检验方向、约束评价规则、保留可精确复用的判断**。它们不是覆盖所有训练输入和读后状态的自动反馈流程。偏好学习并非必须永远采用旧 q/m 形式，但不能现在把排序硬转成 +1/0/−1 奖励，或向未测路径、另一 G、另一呈现条件迁移标签。

## 5. 已落实的方向调整与下一阶段边界

1. 本协议的正收益搜索已收口；不围绕 Q01/Q08 再追逐短路径正例，不追加问卷、G 调优或全局检索扩建。原实现和缓存保留，不撤销历史结果。
2. 当前研究转为报告资源组织、执行器使用、帮助性和成本之间的差异，以及避免多余/不利读取的有限证据。固定 STOP 必须作为参照；若学习策略没有优于 STOP，应如实报告。原有 **3 seeds、384 轨迹、24 次成本负对照 PPO 更新**保持，不能重命名为已学会按情境取得正收益。
3. “质量相当时，若读取确有额外等待，STOP 更划算”是当前部署上的合理倾向，不是本轮测出的数值效用；相当不等于精确质量相等，读取也不保证总生成更慢。**额外等待超过约 3 秒不可接受**继续是研究者的暂定部署约束。本轮没有 Tokkio 完整链路配对计时，不能用 token、GET 次数或不同批次缓存耗时替代。
4. RQ2“读后继续调整”在本任务上仍未得到有效检验。若主目标必须证明该能力，下一研究方案需先建立有实际信息依赖及可观察用户结果的任务，或有真实偏好依据的长期交互；这属于重新设计，不能在本协议失败后悄悄扩大。此处没有新开长期模拟或新的训练阶段。

限制：10 个开发情境、7 位历史用户、1 位评审，非人群估计；来源筛选先于本轮新生成，但历史开发暴露保留。8 个来源库为局部覆盖、2 个完整冻结覆盖；选用的每段来源全文已核验。D 仅经来源筛选为其他话题，不保证无作用，C/D 长度差 24–364 tokens。每条件只有同 G 的一条确定性生成，不能排除表达扰动、长度和中文译文的作用。新增评分、模型调用、API 费用、训练更新均 0。
