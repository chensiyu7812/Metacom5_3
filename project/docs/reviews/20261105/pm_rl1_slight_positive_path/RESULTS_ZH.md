## 复用旧语义排名，直接接上已有人评

核查原始来源时发现，N23完整4段MS均保留了原前缀的BGE分数。原语义顺序把朋友漏邀历史排在第1；当前词语重合顺序将其放到实际第4次读取。这是具体的检索差异，不能归为PPO没有学会选择。

新增的是一个**明确区分身份的静态MS排名对照**：仅在全部合法MS都有原分数、原顺序与分数一致时允许重放，保留全部资源和其他头的动作域。没有替换当前检索器、修改旧产物或把目标标注送给actor。它使用现存分数，不声称本轮重新执行了在线BGE查询，也不证明读后调整的收益。

在该对照中实际执行一次GET_MS后，资源身份、G完整system/user消息、候选G运行身份与G01完全一致。原题中的当前对话角色/文本经字段格式规范化后逐字对应，原题展示的整段过去会话与本次所取历史完全一致。保留原G01证据范围，没有宣称研究者审阅过额外历史。因此**G01“读资源侧略好”的判断可以复用到这一明确的程序和输入**。它仍是同一人的一次旧判断，不新增独立样本，也不变成精确q/m或净收益。

这一观察也有边界：选择该对照是在看过N23之后，属于开发诊断。24个train前缀共248个MS位置中，只有85个保留原分数；只有6个前缀的MS分数完整，其余18个不能静默丢掉新资源后套用旧排名。248是前缀—资源位置数，不是248段独立会话。N05的略好判断保留，但本轮没有替它补全分数或宣称它已可一次取得。

## 对瓶颈和后续推进的影响

当前不能再笼统说“只有不可执行的单资源人评”：N23有一条已核验的静态语义排名路径，接得上真实旧偏好。也不能说“读得越多越好”或“目标历史的事实带来了这个小收益”：自然支持时机本身可以有价值，而本例没有建立特定历史事实的必要作用。

下一步优先修复完整语义检索数据流，使用统一查询、编码与完整来源规则重建24个前缀的全部MS位置，避免混用不同规则的旧新分数。先比较实际动作取得的资源及同输入缓存，尽量复用45条已有参照；不先扩大人评或再教G多展示记忆。静态语义检索与读后调整要分别比较，保持来源完整、动作域一致和计算成本记录。

随后在可复用偏好的路径上补齐检索与PM决策的等待，再接Tokkio实际有效语音测量。将帮助方向、改善幅度和等待分开保留，确定可比较反馈后再进入对应的受限学习分支；无需等所有情境齐备，但也不能将“略好”任意换成0.05，或将相当当作精确零质量差。该路径已有局部帮助方向证据，**综合效用奖励及情境间可比较反馈仍未补齐，本轮没有启动新的自然收益PPO**。
