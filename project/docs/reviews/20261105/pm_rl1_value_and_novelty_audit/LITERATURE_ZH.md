## 文献解读应修正的内容

1. ES-MemEval 原文 §6.3.2 说部分 No-Mem 模型可能因编造貌似合理的经历仍获较高 LT-Mem 分，不是“编造必然被裁判重扣”。其附录还报告 DG 的低 κ 伴随高分集中及较低绝对分差，不能只引用低 κ 就断言全部评分失效或系统性夸大记忆收益。我们自己的裁判反例可支持局部测量风险，尚不足以归因其他论文的增益。
2. ENPMR 的 base 不是无记忆；StratMem 已有人工核验。将现有论文统一称为“没有人评”，不准确。
3. Memory-R1、Memory-T1 已有实测耗时，PACE 直接涉及等待体验。可能的区别应精确到用户侧有效语音端点、相同部署栈和内容依赖获取的净效益，而不是泛称“我们考虑延迟、别人没有”。
4. “小控制器＋冻结G”与“需要时读取”的算法构件已有紧邻先行工作。也不能仅因别人微调大模型就预测小PM必然输；应在相同质量与完整成本约束下比较。

## 当前可诚实定位的贡献候选

- **测量贡献候选**：分开来源可达、内容使用、直接帮助、实际等待，检验看似正向的资源增益是否被无关上下文对照解释；需要独立人评和合适对照，不能预先宣布裁判都偏高。
- **部署贡献候选**：在真实信息依赖差异下，用冻结G外的控制器取得比简单规则、强固定RAG及OneShot更好的质量—等待取舍；全成本包括检索、正文编码、每步PM和生成，不能只报一次MLP前向。
- **顺序贡献候选**：证明读取内容后改变动作/停止有价值，且收益不能被初始query分类、固定多读或一次计划解释；再比较PPO与BC，才能谈RL优化的额外作用。

这三项都是待实证的主张。目前已形成前一项的小规模开发材料，后二项尚无完成结果。没有足够依据宣称“首次”“原创性已确定”或保证投稿档次。
