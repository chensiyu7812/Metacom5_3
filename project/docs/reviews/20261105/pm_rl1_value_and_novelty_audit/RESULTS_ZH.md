# PM-RL1：三个收益问题与原创性的可行性审查

日期：2026-11-05。**结论：现有材料足以支持一次有界的QA收益验证，但不足以确认“收益已足够、顺序RL有必要、原创性已经成立”。** 当前自然支持正收益路线保持关闭；本次没有改成QA训练，没有重启旧寻正例协议。研究主张应由下面三层证据分别支撑。

## 1. 必须分开的三件事

|问题|应当比较什么|现在能判断什么|不能据此判断什么|
|---|---|---|---|
|① 回复本身能否改善|同输入/信息条件下，G或回应方式改变前后|人评指出具体的提问、安慰、解释负担问题；存在可改进对象|尚无一版修订已稳定改善这些问题的验证；不能说只要调G就必成功|
|② 资源是否带来额外收益|同G、同当前输入、同评价范围，OFF/定向资源/其他话题资源；另记真实等待|自然支持10情境未过继续门槛；QA有明确来源支持的信息依赖候选|人名等答案存在不等于模型会用对；资源引用、召回率和正确率也不是综合净收益|
|③ 顺序策略是否有额外价值|共同动作空间中的强固定、规则、OneShot/BC与读后策略；再比较PPO与BC|目前未建立；多段引用只提供检查线索|比OFF好不等于比固定读取好；比固定好不等于读后观察必要；读后策略好不等于PPO必胜BC|

③内部还必须核对两个差距：不同情境的最佳可执行计划是否不同；读取后的内容是否改变下一步决定。前者可以由一次性分类/计划解决，后者才是读后适应。只要一个固定短程序已经足够，就不应为RL增加复杂度。

过去三seed、384轨迹、24次PPO更新只证明成本负对照中策略能减少无效读取，未建立②的自然正收益或③的增量。10题人评的2联合胜出、程度不确定和旧答案复用均原样保留。

“日常情感支持质量不容易提高”应限定为：当前这些情境中，已有回复往往可接受，多种支持策略都合理，额外历史未形成稳定的帮助优势。这不排除改进不自然的追问、个体偏好匹配和长期连续性；这些是不同干预或评价对象。10个筛选情境也不代表96个前缀中只有10个真正需要历史，当前实验不能彻底排除G及呈现方式的影响。

## 2. QA不是空白资产：已复用并重新核验

纠正先前外部分析“9月30日提出QA盘点但一直没做”：当日已有1,261道train/dev结构普查、20道固定来源核查和5项定向追踪。本次核对旧封印、逐行CSV/JSON一致性及owner split，使用已有train/dev隔离文件，不重新读取混合原始QA中的test答案。

### 捷径风险确实存在

- 弃答类225题中222个参考答案为Unknown；这不等于无资源模型实测98.7%正确，尤其类型标签不能进入策略输入。它说明不能用这类题的大量易得分掩盖检索能力。
- 冲突检测240题中174题答案以No/False开头、50题以Yes/True开头，其余16题为其他形式/Unknown。此为文本形式分布，不是“永远答No”的完整语义准确率；解释是否正确仍需判断。
- 时间推理255题中166题只引用一个可见会话；用户建模273题中211题也如此。题型名不能替代资源需求或顺序性认证。
- 官方QA默认完整owner历史，问题所属group不是截止点。直接把这些gold接到自然前缀的严格过去库存会发生范围错配；不能让问题组、capability、gold引用或目标资源ID泄漏给PM/G。

## 3. 新做的15题引用级检查说明了什么

在train按每能力SHA256(owner|group|idx)前3题固定取样，保留全部15例；只是引用级可行性检查，不是完整历史认证或错误率估计。

|类别|具体发现|对收益的意义|
|---|---|---|
|信息抽取3例|最好朋友Emily、尝试正念与冥想、女儿感冒伴哮喘等均有seeker直接来源|信息不在问题本身，存在真实信息依赖候选；仍需OFF/给证据的模型实测，不能预设答对|
|冲突3例|仅讨论过咨询、家人支持但不完全理解、怀念过去的应对能力|一个MS已有引用依据；有些考的是状态限定而非跨会话冲突，完整历史中的时点须确定|
|时间3例|一例引用4会话；一例虽引用3会话，一个会话已有主要回答线索；一例单会话叙述事件结果|多引用≠最小多读，更不等于读后改变计划。需查证据冗余及回顾性复述|
|用户建模3例|开放概括、情绪演变、事后反思推断|不能通用地用字符串匹配或只罚未引用作为正确性|
|弃答3例|都为Unknown、引用为空|不能认证全历史缺失，不能作为免费STOP正例|

这使②在QA上具有比当前自然支持更具体的可检验对象；尚无同栈QA输出，因此实际正确率增益、成本后净收益与学习可达性都是未知。当前资源类型选哪种更好也未建立：原QA引用主要定位MS/私有事件，不能把存在MP/ME抽取库等同于这些短表示已保全所需信息。

## 4. 原创性评估比上一轮更谨慎

[12项先行研究核查表](LITERATURE_ZH.md)包含方法/评价位置与差异。三项新增的紧邻工作尤其影响定位：

1. **StratMem-Bench已区分必需、辅助、无关记忆，并有人工审核及评分核验。**不能把这种分类，或“用对记忆不代表自然整合”，称为首次发现。
2. **冻结LLM外的有限控制器、RL与延迟奖励已有直接先例。**该预印本还报告强优化静态基线胜过其在线控制器，提醒我们要先查简单方法的上限。
3. **Memory-R1/Memory-T1已有实际耗时，PACE涉及对话服务的等待体验。**真实Tokkio有效语音仍可能形成部署差异，但我们尚未完成这项结果，且“考虑延迟”本身不新。

ProactAgent已有按需检索、多类型经验和读/不读配对奖励，Adaptive-RAG已有小分类器选择检索规模。**若第一版只是“把QA混进来，用PPO选记忆”，原创性不够清楚；当前不能认为已经足够。**

有希望形成差异的是：严谨的资源增量测量，内容依赖的获取/停止，相同部署栈上的质量—真实等待取舍，以及相对强规则/OneShot/BC的可重复优势。这是待验证的组合贡献，不是组件并列后的自动创新，也不能保证投稿档次。

ES-MemEval/ENPMR与我们的观察也不构成直接矛盾：任务构造、G、评分和数据范围不同。自身裁判局部夸大/反向只能说明本地风险，不足以宣称其他论文的记忆增益普遍被夸大。

## 5. 怎样用小规模验收降低后续无意义投入

以下是下一阶段候选方案，**不是已执行实验或已冻结的新主训练目标**。先完成来源和测量，再一次性冻结题目、条件、实用门槛、预算和失败出口；不能看到生成结果后改这些规则。

### A. 先验收资源收益，再做策略学习

从现有train中形成最多30个有完整来源/明确时间范围的题，包含清晰事实及经核查的多证据问题，覆盖至少6个owner；不按生成结果挑题。预先登记遗漏/修复与原版差异，无法认证的题在生成前停止或单列，生成后不补换。短抽取的别名、日期/数字规范化须在看模型输出前定义；开放推断题若无可靠评价先不授奖，不能只保留易得分题后称覆盖全部五能力。

固定同一个候选G和输入模板，比较OFF、完整目标证据、同owner其他话题对照，并加入实际可执行的短RAG路径。目标来源是诊断参照，不是数学上界——更简洁的正确资源可能更有效；部署策略不能得到gold位置。建议把Claude提出的“目标证据相对OFF至少+30个百分点”保留为**待冻结的实用筛选门槛**，另要求实际检索路径保留有用增益；它不是显著性证明或全任务成功标准。若题目不足、评价不可靠或实际增益不足，停止该路线，不用继续调PPO补救。

### B. 验收“选资源”确实优于简单读取

即使A通过，还要核查最优可执行计划是否随情境改变。比较固定OFF、固定短RAG/多读、可见query规则、初始一次计划；同时给出按owner/题型的质量、错误与实际等待，混合比例只作明确敏感性，不用人为调比例制造总分优势。自然支持旧相当不能批量变成零质量奖励，QA也不能代替支持质量。

若一个便宜固定计划已接近完整目标证据，则它是有用系统结果，但读后RL的收益空间小。若MP/ME从未比MS更好/更快，不为保留四头叙事强制资源类型均衡。

### C. 单独验收读后信息，再比较PPO

先找来源支持的分叉机制：第一段解决全部问题可停；第一段揭示另一时间/实体或冲突才需继续。完整当前query已经决定读取数量的案例不足以证明它。使用相同检索器、相同动作域、相同成本核算的OneShot/NoText控制，避免把更强检索或更多预算误记为读后观察收益。

只有这层确有差距，再做BC与PPO对比；未超过BC也要保留。这里需要多少分叉、最小效应和重复数，必须在候选数据与实际噪声范围审定后生成前冻结；本次不编造一个已经满足的数量。

### D. 延迟和奖励分别测量

3秒是研究者暂定的额外等待可接受边界，不推出λ=1/3，也不意味着等3秒总值得答对。先使用质量约束下的等待比较/质量—等待前沿，记录用户话语结束到首个有效内容语音，另报首token、完整生成及决策/编码/检索用时。声音“嗯，我想想”的提前播放不能自动算有用回复提前完成。配对控制缓存、预热、负载；未测完整链路时仅报告组件值。

## 6. 当前决策

- ①可继续作为产品/后续生成器质量研究，不能以本次记忆结果否定它。
- ②自然支持分支按失败规则保持收口；QA候选源支持足够值得准备小规模验收，尚不支持“已足够学习”。
- ③顺序RL必要性未过证据关。先排除强固定/规则/OneShot能够解决，才能为PPO投入辩护。
- 原创性已有更清楚的差异候选，但尚不能认证足够。第一版可检验目标是条件性方案，最终题目/主张要跟实际结果收窄，不能提前承诺“提升日常情感支持质量”。

这次能做的是减少已知风险，不可能保证研究一定得到正结果。**值得投入下一次有界验证；现在不值得直接扩大训练或以已确立原创性来推进投稿。**
