## 判断与范围

dot 的主要代码判断成立：此前正式评分队列把 G 请求身份带入评分键；恢复组件尚未接到逻辑评分的最终发布；部分公开测试因为引擎源码位于私有输出目录而整组跳过；学习协调器在若干中断窗口只能安全停止。OneShot 回报回归、独立 NoText 起点、BC 来源和完整 16 条反馈保护原已实现，应保留。

## 恢复的实际边界

- 收集恢复：使用最新连续、封印完整的逐条快照；已完成整批则直接恢复 collected 检查点。后续批次需要先恢复之前完成的政策版本，不自动猜测全目录中哪个分支有效。
- 更新恢复：只能恢复同一 run、batch、CPU Torch 版本和线程设置；若已有后续批次，拒绝回滚旧更新。重算的是未发布的同一次逻辑更新，不多取样、不再请求评分。
- 检查点与哈希封印之间中断、封印损坏、队列已 STARTED 但日志缺失、金额已结算但评分结果尚未封印：停止并要求对账，不能宣称任意时刻自动恢复。
- 未知送达或费用不明：没有自动重派入口。新代码只用于新阶段，旧失败、STOP、费用和资格结论不追溯覆盖。
