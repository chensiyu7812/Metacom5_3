## 4. 本轮采用与停止决定

1. 保留条件策略和证据视图实现，作为有身份的实验候选；不替换正式G、检索、记忆编译器或PM动作。
2. 当前六情境没有独立帮助性结果，不扩大问卷或继续自然支持正例搜索。旧有界历史检验的未通过出口保持。
3. 固定±1窗口不适合作通用最终表示。下一版本应检查实体/指代/时点是否齐全，必要时展开原文；新语义抽取必须从当时合法历史构建，不能为已知题目或答案定制金标记忆。
4. QA资源门槛通过后，优先在该明确任务范围比较强固定一次/两次读取、来源完整的工作视图、简单停止规则和OneShot。新表示先验证保住答案证据及完整率，再比较真实部署等待；只有出现读后状态能改变后续最优动作的证据，才进一步检验顺序PM/RL增量。
5. 不要求四类资源都必须有正收益，也不为了保留RQ2故意拆分一个完整事实。条件策略、信息组织与PM学习的增益分别报告；本轮没有新增训练奖励，事实问答信号还不是原自然支持奖励。
