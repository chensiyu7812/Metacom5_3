# PM-RL1：情境选择与读后调整的正推、反推诊断

研究者要求从必要条件和失败现象两端推断原因。本轮没有把“证据不足”改写成“已训练失败”：真实PM的BC/PPO仍未发生。以下区分结构实测、既有内容观察和待验证机制；不新造q/m、人工答案或奖励资格。

## 1. 两个不同的学习目标

**按情境选资源**要求：可信的质量/误用/成本比较中，不同情境的最佳资源程序不同，而且初始公开观察能提供区分线索。若所有情境都适合STOP或同一固定计划，模型学到统一动作可以是正确结果。

**读后调整**的要求更强：读到的信息会改变后续GET类型、读取量或STOP的优先级，调整带来的质量改善、误用减少或成本节省足以胜过预先固定整个程序。只有回复变了、检索次序变了，尚不等于这一条件成立。

当前OneShot在读取前固定的是head程序；后续每次GET仍用“当前前缀＋已取内容”更新检索，与PPO共享同一个检索器。因此OneShot已经拥有一部分随内容更新的能力。PPO需要证明的额外价值，是根据内容改变后续head/数量/STOP。顺序策略没有胜过OneShot，不能直接解释为资源无用或优化器不会学习。

初始池24个当前前缀均不同。这既不证明缺乏信息获取价值，也不能单靠训练集上不同动作来证明它：足够灵活的一次性策略可能记住这些前缀对应的最佳程序。需要看读后分支、跨情境泛化及同预算基线比较，而不是要求自然数据必须有完全相同前缀。

## 2. 本轮利用已有真实产物重新计算的事实

`replay.py`核对初始包、编码包和实际反馈准备包的manifest，再连接487条程序、真实回复身份与591个实际特征。没有新生成、评分或模型加载。

## 3. 正推：可能在哪一层丢失可学习信号

### A. 当前任务是否需要额外信息

初始24个前缀中，已有简短倾诉邀请、问候、情绪披露、肯定当下感受等情况；不少回复只用当前对话也可能合适。新开发材料5个完整配对里4个候选U相同。旧人评也多次接受不同支持策略。

**推断：任务的资源边际价值可能偏弱，当前前缀已包含不少必要信息。** 这是优先假设，不是全数据结论。早期4组人评资源对照中仍有1组偏好ME侧，而且当时裁判方向相反；不能宣称不存在人类认可的正向资源例子。来源见[历史根因诊断](../../20261023/pm_rl1_root_cause/DIAGNOSIS_ZH.md)。

### B. 资源增量是否被冻结G转成实际改善

当前实际G能响应资源：大量回复改变，已有RS动作进入回复的具体观察。但曾出现历史supporter的话被归给当前AI或用户、无依据具体情境混入回复等问题。P2使用弱监督目标，训练完成尚不等于资源利用能力通过验证。

**推断：有用资源可能被用错，或只改变措辞，没有产生足以影响当前任务的收益。** 在PM阶段G冻结，PM只能学习选择/避开这些结果，不能靠更新自身修好G的说话者归属能力。若G把资源使用成负担，STOP可能就是该冻结G下的合理选择。现有证据不支持把所有错误归因于LoRA，也不支持说G完全忽略资源。

### C. 检索和动作域是否提供了真正可选的好资源

当前代码按字面词集合交集数量排名，查询为当前前缀加已取资源；没有语义适用性判定或已学查询改写。GET由PM选择head，再由固定检索器取该head第一条；PM不直接选择该类任意条目。

**推断：同义但真正有用的材料可能排不到前面；长材料/常用词重合可能抬高与当前任务关系弱的候选；读取后查询也可能被无关内容带偏。** 这些是代码机制支持的风险，未实测发生率。74组顺序改变资源的结果排除了“读取顺序完全没有环境效应”，但尚未证明这种效应有益。不能直接把学习不佳归因于原始数据没有好资源。

### D. 奖励能否保留并正确排序这些变化

q每变一级，U变0.25；本批全部非OFF总成本小于0.127，成本中位数约0.0255。一个q等级的误差约为典型整条程序成本的9.8倍，足以改变动作偏好。另一方面，实际改善若停留在同一q等级、m不变，代理奖励只剩成本差。

已有06B行动预设漏判、MS跨协议收益符号变化；历史同协议重复也曾出现U波动。历史噪声不能直接当作当前协议的误差分布。

**推断：细微但真实的改善可能被离散评分抹平，评分误差又可能制造比成本更大的假优势。** 需要核查排序和具体依据；不能据少量不一致要求裁判零错误。当前也没有证据首先把问题归成“成本系数太大”。

### E. PM是否能从看到的内容识别后续行动

真实actor不是直接阅读原文的大语言模型：当前前缀和资源经冻结BGE编码；同head资源向量取平均，再与数量/成本等特征输入128宽MLP。正文没有被省略，但这不等于主体、时间、建议/完成、冲突/更新等区别一定容易解码。

**推断：表示和小样本监督可能不适合这种细粒度条件决策。** 同类平均可能使关键一条资源的信号减弱。591个不同向量仅排除了精确合并；要证明表示问题，需要可信目标下的拟合/留出或有针对性的表示比较。合成学习实验用的是清晰REDD/BLUE标记，不能验证自然BGE语义表示。

### F. 已有信号能否被优化器学到

GET立即产生成本，质量差在STOP后才返回。组合收益可能需要连续几次正确GET才显现，短期探索容易看见成本而没看见组合益处。初始BC可以缓解这一点，但前提是监督赢家可信。

当前小环境中原PPO确实改善了随机策略期望回报，同时发现价值初始化相对当前随机策略高估、部分种子最终贪心策略未达最优。自然初始池只有24个前缀，不因487条程序而变成487个独立情境。

**推断：信用分配、探索、价值偏差与泛化都是实际风险，但现在不能把真实任务尚未训练的原因称为PPO已失败。** 可信监督都拟合不了时先查表示/目标；BC能拟合而PPO退步时再定位优化器。贪心行为与随机策略期望收益需要分别看。

## 4. 反推：出现什么结果，分别意味着什么

| 将来观察到的现象 | 优先解释 | 有区分力的核查 |
|---|---|---|
| 可信评分下，已测最优计划也几乎不胜过OFF | 已测资源/任务/G的收益上限弱 | 看具体资源是否增加必要信息、G是否正确使用；不能先责怪PPO。已测最优不等于全空间最优 |
| 不同情境的最佳计划不同，但看初始前缀就能选好 | 有情境选择价值，额外读后分支价值小 | 比较OneShot与读后策略；不强求PPO必胜 |
| 确有读后改变最佳后续动作的案例，BC却拟合不了 | 目标冲突、表示或优化拟合问题 | 查同状态标签、文本视图与训练集拟合，不先扩大PPO轮数 |
| BC拟合好，PPO效果差或偏向过早STOP | 探索、终值信用分配、价值初始化或奖励噪声 | 联看价值偏差、实际回报、动作概率和轨迹，区分训练回报与贪心行为 |
| 训练效果好，换前缀/owner不行 | 记忆训练情境、样本不足或分布差异 | 按既定划分看留出表现；增加相同前缀采样不等于增加独立信息 |
| 裁判奖励上升，来源核查或独立质量没有改善 | 代理目标失真或被利用 | 核对具体回复错误和评价分歧，不能用训练奖励自身证明成功 |

## 5. 当前优先级与合理结论

最先应检验的组合解释是：**当前任务/冻结G下的资源增益较弱，再叠加评分的粗粒度和错判，导致有用动作优势稀少或不稳。** 这是综合已有证据的判断，不是按概率估计的归因比例。

对“读后继续调整”还应单独检验：共享的动态检索器是否已承担了主要内容适应，剩余改变head/数量/STOP的空间究竟多大。当前结构支持研究这个问题；结果可能支持情境化一次性策略，也可能支持读后策略，两者均不应预定。

目前优先级低于上述问题的是“PPO实现完全不会学习”；受控实验已反驳这一笼统说法。自然表示、探索和价值初始化仍需实际反馈后定位。旧4 GET/2048硬上限、本批正文尾部被截断、资源永远改变不了G，都不符合当前全部事实，不能继续作为默认解释。

下一项诊断应使用已生成材料：在事先确定的覆盖范围内识别有据的资源增益/损害、已测最优计划的情境差异，以及同一次读取后的STOP和不同后续程序。将原始来源核对、评分排序、BC拟合和首次PPO行为串起来。无需从零再生成487程序，不要求每条都找人评分，不把已答问题重发，也不把本分析当成训练成功或新奖励。
