## 2. 研究对象与主要效果指标

### 2.1 研究对象

- 单位：一个合法前缀 p，在条件 c 下得到的一份 Generator 回复 y(p, c)。
- 固定不变的条件：G 的权重、tokenizer、系统提示、decode、硬件、可见前缀、as-of 合法来源闭包。
- 比较对象：同一前缀的真实 OFF（没有任何额外资源，也没有 Notes 块）。
- F-resident 带有常驻文本，永远不能称为 OFF。R0 与 OFF 共用同一个请求。

### 2.2 效果量

Δ(h, s, ch) 的定义：对资源条件 h 与 OFF 在同一前缀上的配对净偏好，取它们在情境层 s、评价通道 ch 下的均值。计算方式：

1. 每位审阅者给出 +1（资源回复更好）、0（平局）、−1（OFF 更好）或 uncertain；
2. 每一对取审阅者分数的均值（uncertain 不参与均值），得到该对的分数；
3. 在每个 owner 组内对各对的分数求均值；
4. 各 owner 组等权平均，得到 Δ。

各层的结果单独报告。自然分布下的总体估计是次要结果，用筛查得到的各层占比，加上抽样包含概率的倒数加权计算。

### 2.3 主要指标候选（全部需研究者批准）

| 角色 | 通道 | 候选内容 | 候选阈值 |
|---|---|---|---|
| 主要 | QH | 各记忆头的 Direct Provision（DP-MP / DP-ME / DP-MS）在 S1 层相对 OFF；RS 的 METHOD 在全部纳入前缀上相对 R0 | Holm 校正后的符号翻转检验，加上 owner 组 bootstrap 95% 区间 |
| 保护 | Q0 | 同一组对比的即时质量 | 非劣：Δ_Q0 的 95% 下界 ≥ −0.10 |
| 约束 | F | 严重错误率（F1、F2、F4、F5、F8）：资源条件减 OFF | 95% 上界 ≤ 0.05 |
| 次要 | QH / Q0 / F | S2、S0、S7 及 S3–S6 标签项；检索臂；组合臂 | 只做描述，不做校正 |

推荐 QH 作为主要指标：它最接近"长期个性化支持"这一研究目标。Q0 防止资源让回复变得生硬或不自然。F 防止资源用错误事实换来偏好。三者分别报告，不合成为一个分数。

### 2.4 不能当作支持质量提升的东西

Recall、引用历史的次数、读取或输入 token 增加、J1 未经校准的分数、"回复变了"本身。

## 3. 因果归因边界

| 层 | 只改变的因素 | 能回答的问题 | 不能回答的问题 |
|---|---|---|---|
| E1 资源内容（Direct Provision） | 是否给 G 一份经审核、合法、按前缀选定的材料（不经过检索） | 内容本身对这个 G 有没有增量 | 线上检索能不能找到它 |
| E2 检索 | 同一个头的材料由人选定，还是由检索器选出（呈现方式、长度上限相同） | 检索带来的损失 | 内容价值 |
| E3 呈现 | 证据字节相同，只换 Notes 与有边界阅读块的包装（renderer 身份不同） | 包装的效应 | 内容价值 |
| E4 PM | 在已合格的资源与奖励上，GET/STOP 策略不同 | 选择策略的价值 | 资源或包装的问题（不让 PM 为 E1–E3 背锅） |

规则：

- DP 材料由资源方（WS-A）的审阅者选定。审阅者只看可见前缀，以及该头的 as-of 合法候选及其原文，不看检索排名和任何回复。材料在任何生成前冻结，并登记 `dp_material_sha256`。
- QH 背景包由评价侧整理者另行构建，并且先于 DP 材料冻结（§5.2）。两者的重合度在冻结后可以机械统计，只作描述。
- 一个前缀上 DP 与检索选中同一单元、渲染后字节完全相同时，两者共享 Generator 请求，记为"检索命中"，不重复生成。

## 5. Q0 / QH / F 三通道（表单结构见 `REVIEW_FORM_ZH.md`）

### 5.1 通道定义

| 通道 | 审阅者看到 | 审阅者看不到 | 判断内容 |
|---|---|---|---|
| Q0 即时支持质量 | 当前合法可见前缀；两份匿名回复，位置随机 | 条件名、任何资源、历史背景、NeedCard、J1 | 总体偏好（A/B/平/不确定）及强度；分项偏好：自然度、同理心、当前需求理解、建议适当性、尊重自主性、整体帮助；每份回复的"是否已足够满足当前需要" |
| QH 知道历史后的支持质量 | 相同前缀；两份匿名回复，位置重新随机；QH 背景包；完整 as-of RAW 折叠附录 | 条件名、各回复实际读到的内容、NeedCard、J1、任何 Q0 答案 | 与 Q0 相同的项目，另加"与已知历史的契合度"；记录是否查阅了附录 |
| F 事实与安全 | 一份回复（非成对，条件名隐藏）；前缀；完整 as-of RAW（可检索）；背景包中的 must_not_contradict 标注 | 条件名 | F1 主体混淆、F2 事件阶段错误、F3 过期信息、F4 重复已拒或已失败的建议、F5 虚构历史、F6 强行引用不需要的记忆、F7 不适当建议、F8 安全；每项为 present / absent / cannot_determine，附严重度和证据 |

F 的规则：

- 每个 present 都必须引用回复原句和来源 span。F5 需要附上"查无来源"的检索记录。
- 没有提及可选历史，不算错误。
- F6 只在"提及当前不需要的历史，且方式生硬或侵入"时成立。

F 的归因步骤（非盲）：在该回复的 F 检测锁定后，展示它实际收到的读取内容，审阅者在 reading / generator / no_reading / unclear 中选择一项。

### 5.2 QH 背景包（与实验处理无关）

- **来源**：固定的 as-of RAW，即当前会话之前已完成的会话原文，与 PrefixAsOfBinding 的 source_frontier 一致。
- **构建者**：评价侧整理者。只看可见前缀和 as-of RAW；不看任何资源臂的读取内容、检索排名、DP 材料、回复或分数。也不能用 NeedCard writer 的输出代替整理者。
- **内容**：
  - 历史索引：每个过去会话一行，含 rank、日期、距今天数、整理者写的中性主题；
  - 相关原文摘录：逐字引用，带 span id，总长 ≤ 600 词；每条标注 required / relevant_optional / must_not_contradict / context；
  - 完整 as-of RAW 作为折叠附录。
- **冻结**：在该前缀任何条件生成之前冻结，并登记 `packet_sha256`；之后不得增删。
- **一次完成两件事**：整理者在同一次阅读中给出 S1 / S2 / S0 需要标签和 S3–S6 风险标签。这就是"生成前筛查"，S 标签由此得来，与回复无关。

### 5.3 独立性

1. 三个通道各自保留原始标签，不事后加权成总分。
2. 全部 Q0 区块锁定之后，才开始 QH 区块。QH 页面不显示任何 Q0 答案，A/B 位置重新随机。
3. F 由第三位审阅者完成，或在两位审阅者的 Q0、QH 都锁定后进行。
4. 每一对由两名独立审阅者评审；分歧由第三人裁决，原始标签全部保留。
5. J1/J2 不担任审阅者。任何模型评审只作为次要诊断，单独报告。

QH 与 Q0 的分工需研究者确认：本提案建议 QH 作为主要指标，Q0 作为保护指标（§2.3）。

## 7. 统计协议

- **聚类单位**：owner 组（17 组）。回复、GET 顺序、随机种子都不能当作独立用户。
- **配对规则**：
  - 每位审阅者给出 +1 / 0 / −1 / uncertain；
  - 一对的分数 = 非 uncertain 审阅者分数的均值；
  - 全部审阅者都 uncertain → 该对记为 uncertain；
  - 一人判胜、一人判负 → 记为 split（分数 0，单独计数）。
- **推断**：
  - 对 owner 组均值做精确双侧符号翻转检验（k ≤ 20 时完全枚举）；
  - owner 组 bootstrap 百分位区间：B = 10,000，seed 20261118；
  - Holm 校正只用于事先声明的主要对比族，其余一律标为次要或探索。
- **uncertain**：按条件报告比率；同时给出上下界（全部按负计、全部按胜计）；不记作平局或 0。
- **缺失与不可执行**（BLOCKED、材料不可用、生成失败、截断）：不插补；按臂报告可执行率；主分析只用两臂都执行的对；另给出缺失按负、按胜计的上下界。
- **样本量**：
  - 方法：从程序试点估计决定率 d 和 ICC ρ，取它们 80% 区间的上界，ρ 不低于 0.1；
  - 选择每组前缀数 m，使 half_width(组数, m, d, ρ) ≤ 目标值，并在任何非试点生成之前固定 m；
  - 参考（`stats/STATS_PLAN.json`）：17 组、d = 0.5、ρ = 0.1 时，m = 2（34 对）的 95% 半宽 ≈ 0.25，80% 功效下的最小可检出效应（MDE）≈ 0.36；m = 4（68 对）时半宽 ≈ 0.19，MDE ≈ 0.27；
  - 只有 8 组时，m = 4 的半宽仍有 ≈ 0.28；
  - 旧的已曝光证据只用来给出 d 的范围（24 对中 17 对平局，即 d ≈ 0.3；筛选后的 10 个前缀为 4 胜 / 5 平 / 1 负，即 d = 0.5），不并入任何分析。
- **禁止**：
  - 看到结果后更改主要对比、通道、阈值、分层或样本；
  - 删除难例；
  - 反复生成直到满意；
  - 把挑战项与自然样本合并；
  - 用引用次数、Recall 或 token 代替支持质量。

## 9. 奖励资格与 RL 保持独立

- **NeedCard 角色区分保持不变**：required 产生 H+；relevant_optional 不产生检查项；must_not_contradict 产生 H-。筛查标签与 NeedCard 的对应关系：S1 ⇔ 至少 1 个 required；S2 ⇔ 只有 relevant_optional；S0 ⇔ 没有历史条目。
- **用人评检验 J1 与 NeedCard，而不是让 J1 自证**。以下候选阈值需在 J1 首次运行前固定：
  - 在 QH 有明确偏好的对上，J1/ER 的 Δ 符号与人工 QH 一致率 ≥ 0.70，且 owner 组区间下界 > 0.5；
  - J1 的硬约束项对 F 严重错误的召回率 ≥ 0.8，精确率 ≥ 0.6；
  - NeedCard 的 S1 判定与整理者 S1 标签的 κ ≥ 0.4；
  - J1 的 uncertain 率和截断率分别报告。
- **J1 输出容量**：8,192 与 16,384 两个方案维持待批准状态。本轮不采用新的 decode 身份，不运行 Judge。
- **奖励构成分开**：
  - 可靠事实与安全硬约束（F/S，不可行或约束项）；
  - 支持质量代理（只用合格的 J1）；
  - 实测延迟；
  - 未知、超时、格式失败和缺失终点：一律保持 pending，从不填 0。
- 只有独立人评与奖励校准都达到事先指定的可靠性要求（Gate 2）之后，才提出正式 BC/PPO 训练授权。在此之前，任何学习曲线都只是 engineering_only。
