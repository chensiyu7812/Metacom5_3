**四、已经做的新任务免费 census**

从 sanitized sessions 构造候选切点：当前 seeker 后紧接 supporter，当前 session 至少有一个过去 session。每 session 只选一个 hash 决定的预备切点；不使用任何新回复效果选样。

- Train：p12、p9、p5、p11、p17、p3、p6、p13、p16、p8、p2、p10；Dev：p1、p15、p18；Test：p14、p4、p7。

- 168 个预备前缀的纯对话文本 token 中位数 259、最大 807；这是冻结 Llama tokenizer 的实测，不含最终 RL1 系统提示和 chat wrapper。
