- A：两位参与者一起看题，主要阅读中文，各自给出第一反应，研究者先说明第一反应大多一致，随后确认最终判定完全一致；目前提交的是一份合并答卷。
- B：研究者报告为 GPT-6 Astra（极高），生成判断时未见 A 的答案或理由。
- 这支持把 B 当作未受 A 答案直接提示的探索性 AI 对照，来源依据是研究者说明。未取得 API 快照或解码日志，因此不额外推定技术参数，也不替换项目冻结的正式 teacher。

研究记录可以写：“两名参与者共同审阅中文材料并形成一份联合判断记录，参与者确认最终判定完全一致。”由于共同看题、未提交逐人独立原始记录，不能计算双独立人评一致率，也不能把同一个 A 文件计作两份独立判断。参与者人数为 2、收到的判断记录为 1，这两项同时保留。

主要看中文使翻译问题成为需要优先核查的解释。已确认现存 B HTML 将 pet 翻成猫/狗；A 的实际显示 HTML 未提供，因此仍不声称已证明 A 使用了完全同一份译文，也不把所有分歧归因于翻译。

## 现在只做小范围口径澄清

打开同目录 `判题口径澄清_6例.html`。每例给出中文说明、关键证据和可展开的原始英文。可以记录“已理解 / 有不同理解 / 暂不确定”，只需解释仍有疑问之处；允许部分保存、导出及恢复。也可以直接在对话里回复疑问，不要求另交六个新胜负标签。

六例分别说明：译文不能增加事实、摘要先核对事实、直接事实答案可以足够、双方同样差仍可相当、Unknown 与编造细节、可合理保留的回复风格分歧。它们按已发现的问题选取，包含原判断合理的对照例；不是随机核验集，不用于估计总体准确率，也不是六个必须通过的新门槛。

这一轮只澄清既有规则。页面没有预填“正确胜者”，讨论记录不覆盖原始 verdict/rationale，也不自动生成共识 reference 或 PM 标签。材料由已看过人类及 AI 结果的助手整理，必须按事后辅助说明报告。

后续依据这些澄清确定实际需要复核的范围。若要把联合人类记录正式用于替代既定双独立主评，需要单独明确修改条款及证据局限；本轮只是来源补记和说明材料，不改变当前研究合同。现阶段无需重发整套试卷，少量澄清也不能宣称恢复了双独立证据。

正式推进仍是：参照材料与使用方式收口 → 单独授权的 teacher qualification → amount/top-k calibration → 冻结 k* 与容量 → 正式 effect labels 与 PM training。

## 本目录

- `provenance_addendum.json`：原始来源说明与解释边界。
- `判题口径澄清_6例.html`：离线阅读及可选备注页面，不发送数据到网络。
- `clarification_examples.json`：六例说明及逐字保留的英文来源，无系统 ON/OFF 身份。
- `build_clarification.py`：生成本页面的代码。
- `verification.json`：来源、展示及导出复核结果。

依据：原始 A JSON、B HTML、已完成的重点案例证据，以及项目 V2 人评 instrument。原题和参考不因说明材料而改变。
