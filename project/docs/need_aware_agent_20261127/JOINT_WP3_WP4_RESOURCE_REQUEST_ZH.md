## 0. 上限怎么来的

GPU 秒数都是最坏情况（每个请求都输出满 `max_new_tokens`），用 WP2 账本的实测数据计算，可以用 `scripts/need_aware/naa_plan.py` 复算：

| | Qwen3.5-9B | Gemma-4-12B-it |
|---|---:|---:|
| prefill | 5,298 tok/s | 1,825 tok/s |
| 解码 | 21.2 tok/s | 12.8 tok/s |
| 加载（含 spawn/guard/IPC） | 38 s | 46 s |
| 短输入单次前向（<1,600 token，P50） | 0.21 s | — |

每个请求的输入 token 用两模型 native tokenizer 实际物化后的 P95。A 原先提出的 115,200 s 是“不含实测的候选上限”，A 自己也注明了这一点；本申请用 B 的实测上界替换它，合计 **49,600 s**。

## 1. 共同条件（全部块适用）

- **代码**：每块执行前，manifest 都绑定请求、解码、数据、代码、模型和 adapter 的 SHA；每块一份批准文件，绑定 manifest SHA 和干净 HEAD。研究者批准后，B 依据批准原文生成批准文件，并注明“依据书面指令，非签名”。
- **设备**：单张 A6000（`GPU-ba5f65be…`，48 GB，当前空闲）；顺序执行，不抢占其他 GPU 作业；使用历史设备 guard 和固定锁。
- **存储**：数据盘剩 275 GiB。根分区剩 1.4 GiB，本申请不往根分区写任何东西；存储 guard（根分区 ≥1 GiB，数据盘 ≥4 GiB）每次请求都检查。根分区清理清单见 B_WP2_RUN_ZH §4，由所有者决定。
- **运行器**：WP2 运行器加类型化停止；teardown 计入占用，并在上限内预留 10 s；hash 链账本、精确去重、断点续跑。单请求最多 2 次尝试，总重试不超过可执行数的约 5%，每个生成器标签最多 2 次加载。
- **技术烟测**：每块每个生成器的前 16 次调用（训练是前 20 步），计入额度；只检查格式、身份、EOS、耗时和显存，不看正确率。
- **零付费 API、零外传、不开正式测试集**；WP2 的 170 个缺口不补跑。B 运行，A 封存后做 CPU 评分；AI 每小时最多检查一次；到达硬上限即停，不扩容。

## 块 W4-T：训练（U2 普通 SFT 与 U3 配对适用性监督，Qwen3.5-9B）

- **配置**：A 的 `TRAINING_CANDIDATE.json`：
  - 数据：fit 3,716 行 / 1,239 组 / 620 个来源家族；
  - 超参数：1 epoch、microbatch 1、累积 8、465 步（上限 500）、学习率 2e-4、weight decay 0.01、warmup 25 步；
  - LoRA：r8、α16；
  - 损失：U3 为 SFT + 0.1 × softplus(0.5 − 选中动作 logp + 不相容动作 logp)；U2 执行同样三个分支，但辅助项系数为 0，以实现计算量对齐。
- **B 的真实契约**（`TRAIN_CONTRACT_V11.json`）：
  - fit/tune 全部行的提示 = 推理时的 chat_ids，结尾 = 原生 `<|im_end|>`；
  - 与开发集和确认集的 440 个 owner 没有重叠；
  - 序列 P50 181 token、max 242；
  - 三个分支每个 epoch 共处理 1,885,303 token；
  - 显存：bf16 权重 18.8 GB 加很少的激活，48 GB 足够。
- **需要在训练前共同冻结的一项**：A 候选的 `q_proj/v_proj` 在 Qwen3.5 上只覆盖 32 层中的 8 层（16 个模块，111 万参数），因为其余 24 层是线性注意力。可选方案 `qv_all_layers`（q_proj、v_proj、in_proj_qkv）有 40 个模块，覆盖全部层，347 万参数。U2 和 U3 必须使用同一选择；不做损失试错。
- **时间上界**：每个样本 3 个分支 × 4 倍短输入前向（0.21 s）= 2.5 s → 每种方法 9,382 s；tune 评估 333 s；再加加载、保存和 teardown。

| 子项 | 申请上限 |
|---|---:|
| U2，含 20 步技术烟测 | ≤10,800 s，≤465 步 |
| U3，含 20 步技术烟测 | ≤10,800 s，≤465 步 |

如果烟测实测后，预计时间超过上限，就停止并报告，不自动延长。产出两个带 SHA 的 adapter 和训练回执（加载、保存、teardown 时间，有效目标 token 数，辅助计算开销）；基座 checkpoint 不变。
