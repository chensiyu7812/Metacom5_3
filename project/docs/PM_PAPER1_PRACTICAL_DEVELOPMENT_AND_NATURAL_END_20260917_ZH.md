## 自然结束的实际含义

原服务强制接受 60/256 token，不能通过省略参数实现自然结束。新本地执行器以模型 EOS/EOT 为正常结束；不设置任务级输出 token 上限。底层 `max_new_tokens` 只表示模型上下文剩余空间，防止默认短限制重新生效。

保留技术保护：上下文耗尽、非推理请求 300 秒／Qwen 推理请求 900 秒、连续四次完全重复的 32-token 片段。触发任何保护均标为未自然完成；不改成语义 uncertain 或 equivalent，不删除失败。

短理由是表达偏好，不设 600 字符拒收门。新 parser 接受完整 JSON 或完整 Markdown JSON 围栏；Qwen 单独分离完整 thinking 与最终 JSON。拒绝重复键、混杂多个答案和不完整最终输出。历史 Gemini parser 不变。

模型逐个在 A6000 BF16 上运行；固定版本、原生 chat template、完整输入。Selene/Compass 使用 greedy；Qwen 开 thinking，采用固定权重版本官方模型卡的通用任务配置：temperature=1.0、top_p=0.95、top_k=20、min_p=0、presence_penalty=1.5、repetition_penalty=1.0，按题固定 seed。依赖、权重摘要、输入和实际终止原因随结果保存。

裁判执行采用 vLLM、批内最多 4 条请求，Selene/Compass 服务总上下文 32,768 tokens，Qwen 为 131,072；`max_tokens` 仅取服务上下文减去完整输入，不设独立短输出上限。Qwen 不修改原生 RoPE。与单请求 Transformers 的 Summary 诊断分开记录后端；批处理耗时不进入正式客户端延迟结论。Selene/Compass 为 vLLM 0.10.1；Qwen 使用支持该架构的独立 vLLM 0.19.1 环境。模型文件不量化。

Qwen 最初使用 temperature=0.6、presence_penalty=0，实际对应官方“精准编程”而非通用任务建议。发现持续推理和一条 900 秒超时后纠正该配置；46 条已结束呈现、4 条中断中的请求、原始理由及身份快照完整保留在 `qwen35_9b_coding_profile_diagnostic/`，不混入新版 160 条比较。该纠正由官方固定版本[模型卡](https://huggingface.co/Qwen/Qwen3.5-9B/blob/c202236235762e1c871ad0ccb60c8ee5ba337b9a/README.md#best-practices)支持，不按是否更贴人评选择参数。初始化兼容失败和更早中断的 Qwen 预填充也单列工程日志。

换序统计衡量各自完整运行配置的判决稳定性。Qwen 使用采样推理且按 presentation ID 固定 seed，因此其两顺序不一致可能混合顺序效应与采样波动；不把该统计全称为纯位置偏差。三款的后端、解码方式有意分别合理配置，比较结论针对“模型＋配置”，不是剥离所有实现因素的权重因果排名。

本地生成时间累计 4 小时为操作边界，不是准确率门；下载和环境配置另记。本轮 API 增量为 0。官方付费模拟器、评分器不因生成器长度建议自动改变参数。

运行记账按模型实际占用 GPU 的累计生成墙钟时间计算。初版执行器把批内重叠的请求耗时相加，会过早触发边界；新版已修正，旧代码／授权快照和所有结果保留。中断的最初 Qwen 预填充保守预占 900 秒；精准编程配置诊断的实测约 1,869 秒也计入总额。为旧配置准备的续跑没有执行；新版重新比较同一 160 条，额外消耗如实作为开发诊断记录。

严格解析与明确格式修复后的判决分开报告。离线补充视图处理明确的 `rationationale`／`rationacle`／`rationable` 字段拼写、字段名空白、裸 enum、纯文本理由引号，以及完整键值之后缺失的单个外层花括号。Selene 先理由后结论版另处理结果末尾单个句号，以及明确否定备选、只肯定一个标签的结果段；不从理由推断赢家，不消解相互矛盾的结论。未识别格式仍留缺失，原始状态不改写。历史 Gemini 的 600 字符限制也另做零调用重解析敏感性；原始结果不覆盖。

## 对旧条款的覆盖

新增第三候选及自然结束，覆盖旧两模型提案的候选范围、1024 输出 token／600 理由字符限制；放宽开发阶段不可看回复质量、不可复用材料改提示的要求。原因是按研究者意见允许务实迭代，避免过短输出限制干扰测量。

旧 Gemini、人评和生成结果全部仍有效，但属于旧配置。新旧模型比较解释为配置比较，不能将全部差异归因于权重。PM 的二元实质收益目标和官方指标层级不变。

正式生成前，将统一自然结束策略用于各比较组，并更新容量、实际延迟及调用预算。此次是开发诊断，不冒充已完成正式全栈冻结。

## Selene 输出顺序诊断

初始 JSON 结果出现理由判 B 正确、标签却选 A 的明确矛盾。官方模板使用先 `**Reasoning:**` 后 `**Result:**` 的输出布局。因此在共享 4 小时生成预算内追加一次 160 呈现的格式诊断：只替换输出格式句，所有证据、四类标准、权重与 greedy 设置不变。官方原始 pairwise 模板的强制 A/B 规则不采用，因为它不符合本研究允许相当和无法判断的任务。该版本是受官方布局启发的格式适配，不声称原样复现官方完整提示；不根据同卷分数继续循环改提示。
