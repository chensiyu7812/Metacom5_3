优先准备单一 Claude 单评候选 C，沿用完整来源、原 q/m、阅读政策及原资格标准。暂拟 Sonnet 5.5/high/adaptive：依据是已确认的可用接口及价格，尚非按本任务表现选出的模型。Opus 只作成本比较，当前没有准备多模型赛马或自动升级重试。旧 DeepSeek 单评/审查保留为历史证据；原 S/A 259 次提案仍未激活，C 若被选定则替换该下一阶段提案，不把 97 次叠加到 259 次之后。

Claude 还可承担有限来源核查或最终的跨模型敏感性评价。角色须预先明确：用于调流程、训练奖励或挑模型后，同一配置在终评中的结果只能视为同代理评价；另一个模型家族也不自动是独立金标。Claude 的建议可供真人核对，不能把 AI 输出填成人工标签。它不解决原验证材料暴露、test 只有三个 owner、执行器质量未证实或缺少真实 BC 的问题。
