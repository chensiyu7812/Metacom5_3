## 三、按研究问题逐项分析

1. **当前目标与边界**：16状态的三臂回复均未偏离当前请求；Q07/Q08自然前缀未强行复述历史。
2. **人物与主体**：Q05（用户、经理与第三方）、Q03（所问家庭成员与另一位家属）正确；本批没有主体交换错误。主体能力的压力测试见第五节。
3. **建议/计划/执行/结果**：最主要的语义失败类型。Q02“提议→帮助已在进行”（A0两次、A1笔记一次），Q06“计划/考虑→已采取步骤”（三臂）。A2解释的stage字段本身也不可靠：Q06-S1把计划、意图类表述标成performed；当前感受与“想聊聊”这类当下表达也被迫填performed——schema缺“当前状态/报告”阶段，是表示设计问题。
4. **报告时间、事件时间与当前适用性**：Q04是唯一跨S0/S1稳定暴露的时间缺陷：引文中的相对时间被重新锚定到当前日期。A2在S0因状态的applicability错误而犯错，在S1虽未修正状态却碰巧没有犯错，不能算作状态带来的修复。Graphiti的“计划的valid_at=陈述时间、未来日期留在事实文本”正对应这一缺陷。
5. **未知与否定**：Q01-S0/Q05-S0/Q06-S0三臂都给出有范围的未知，没有“全历史不存在”的过度否认。
6. **S0→S1更新**：A2在Q03、Q05正确吸收新证据；A1在Q03-S1未修订旧笔记并把错误传给G。Q04两种解释都没有用新可见的便条日期修订适用性。
7. **语义状态遗漏**：A2每条最多4项主张，Q06-S1需要列举多项并区分阶段时撞512 token上限；Q01-S1同样因逐条复制证据而截断。
8. **G是否利用理解**：Q03-S1（A2状态→正确家庭成员）、Q02-S0（stage=suggested→未预设帮助）可见利用；Q04-S1 A2状态未修正但G仍避开错误，说明G并不总按状态行事。
9. **错误理解是否传播**：Q03-S1（A1）、Q04-S0（A2）各一例明确传播。
10. **Notes能否解释GSWS收益**：可以解释大部分。可比的10状态上8:9；A2的额外优势主要来自A1的4次引用格式失败（笔记引用了会话级ID而非话轮级ID），而这类失败是接口约束问题。目前**没有建立专门表示的独立增量**；按既定口径，这不否定工作记忆逻辑架构与专业语义能力的价值。

## 六、研究决定

1. **GSWS固定供证诊断到此收口**，不重跑、不改提示追分。结论：同信息下的专门状态表示未显示相对普通笔记的独立收益；同步解释的等待成本过高。
2. **身份交付作为系统上下文合同推进**：所有竞争方法共享同一身份说明；只在A场景改渲染；不追溯修改旧评分；不把它报告为语义能力突破。
3. **Semantic Capability Layer的首个学习目标**定为“说话人/阶段条件化的三分类证据状态：supported / contradicted / not-established”，主体由宿主结构交付，模型只学阶段、否定与未知。MiniCheck可作为支持分量复用，NLI的矛盾分支不可直接复用。
4. **时间**：先实现确定性的“报告时间vs当前时间”交付（每条证据带报告日期、计划的valid_at=陈述时间），再评估语义层是否还需学习适用性。
5. **调度**：语义能力只在PM判断存在缺口时调用；本批Q05/Q07/Q08等状态说明M0+R0与不调用能力是合法成功路径。尚无支持BC/PPO的动态收益证据，不启动。
