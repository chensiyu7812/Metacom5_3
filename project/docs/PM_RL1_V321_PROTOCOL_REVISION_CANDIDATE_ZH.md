## 3. Q0 / QH / F 修订（review-spec-v2-candidate）

- **QH**：
  - 仍是主通道，衡量长期支持质量；
  - 背景为完整 as-of RAW 加中性索引，同一前缀的所有条件完全相同，并在生成前冻结；
  - 审阅者说明改为：“请以一个了解此人过往的支持者的视角，判断哪份回复此刻对此人更合适、更有帮助。是否提到过去的内容本身不是评判标准。”删除 #17 中“相关但可选”等暗示分类的措辞。
- **Q0**：仍是即时质量的保护通道，不显示任何历史。
- **F**：
  - 仍是事实与安全约束；
  - 审阅者可以检索完整 RAW，但看不到 must_not_contradict 等角色标签；
  - F6（强行提及不需要的记忆）由审阅者自行判断；
  - 每一项“有”都必须引用证据。
- **审计侧**：
  - 持有需要标签、条件映射，并负责 F-A；

- **人员**：同一前缀的筛查整理者默认不担任该前缀的审阅者。人手不足时，记录重叠，并做剔除重叠前缀的敏感性分析。
- **显示**：回复按生成原文以纯文本显示，不解释也不修改 HTML 实体；技术痕迹由审计侧另行计数。
- **表单**：#17 的 `REVIEW_FORM_ZH.md` 仍是结构基础，本轮改动如下：

  - QH 的“背景包”改为完整 RAW 加索引；
  - QH 锁定后新增一道盲态探针：“你认为哪份回复参考了过去的对话？”只用于描述；
  - F 删除 must_not_contradict 的显示；
  - F-A 移到审计侧。

## 4. 统计（17 个 owner 组；详见 `stats/STATS_V321.json`）

**估计量**：对 OFF 的配对净偏好（+1 / 0 / −1，可取两名审阅者的均值），按 owner 组等权平均。

**检验与区间**：精确符号翻转检验，加 owner 组 bootstrap 置信区间；精度规划使用 t 分布（df = 16）。

**精度规划**：决定率 d = 0.5，80% 把握度，双侧 95%。

| 每组对数 m（总对数） | ICC 0：半宽 / MDE | ICC 0.1：半宽 / MDE | ICC 0.2：半宽 / MDE |
|---|---|---|---|
| 2（34） | 0.26 / 0.36 | 0.27 / 0.38 | 0.28 / 0.40 |
| 4（68） | 0.18 / 0.26 | 0.21 / 0.29 | 0.23 / 0.32 |
| 6（102） | 0.15 / 0.21 | 0.18 / 0.26 | 0.21 / 0.30 |
| 8（136） | 0.13 / 0.18 | 0.17 / 0.24 | 0.20 / 0.28 |

**非劣界**：要使真实 Δ = 0 时 95% CI 下界以 80% 把握高于 −margin，每组需要的对数如下。

| margin | ICC 0 | ICC 0.02 | ICC 0.05 | ICC 0.1 |
|---|---|---|---|---|
| 0.10 | 27（约 460 对） | 54 | **不可达** | **不可达** |
| 0.20 | 7 | 8 | 10 | 18 |
| 0.30 | 3 | 4 | 4 | 4 |

- 在 17 组的设计下，只要 ICC ≥ 约 0.04，无论每组多少对，−0.10 都不可达，因此只能作为讨论候选。
- m = 4、ICC 0.1 时可达到的 margin 约为 0.29；m = 2 时约为 0.38。

**F 严重错误率**：采用精确 Clopper–Pearson 单侧 97.5% 上界，设计效应取 1.1。

| 每臂回复数 | 0 例 | 1 例 | 2 例 |
|---|---|---|---|
| 16 | 0.23 | 0.34 | 0.43 |
| 34 | 0.12 | 0.17 | 0.22 |
| 68 | 0.06 | 0.09 | 0.11 |
| 102 | 0.04 | 0.06 | 0.08 |
| 136 | 0.03 | 0.04 | 0.06 |

- 要证明上界低于 0.05：0 例时每臂约需 80 份，1 例时约需 122 份。所以 +0.05 在每臂 34 份回复时无法证明，只能作为讨论候选。
- 可以检出“有害”：配对精确符号检验在“仅该臂出现严重错误”达到 6 例、且 OFF 一侧为 0 时能检出（未考虑聚类）。

**判读规则**：

- superior：95% CI 下界 > 0。
- non_inferior：下界 > −margin，且 margin 必须事先经研究者确认。
- inferior：上界 < 0。
- 其余一律判为 inconclusive。

另外四条：

1. inconclusive 表示精度不足，不能解释为“系统无效”。
2. 不显著不能解释为非劣。
3. 严重错误“未观察到”不等于“率低于 0.05”，必须报告上界。
4. 分层结果分开报告，不单独下显著性结论，除非事先列为主比较。

**缺失与不确定**：

- 不确定按全负 / 全胜给出边界，不做插补；
- 技术失败记为 pending，按臂报告，不填 0；
- 缺少审阅者答案的对不进入点估计，只由边界覆盖。
