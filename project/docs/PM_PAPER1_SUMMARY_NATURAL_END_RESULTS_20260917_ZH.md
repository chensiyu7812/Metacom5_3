## 内容检查

部分 OFF 会在没有用户记忆的条件下自行写出带日期的“记忆片段”；另一些把官方 system prompt 中的演示人物与经历当作当前用户资料。解除上限后，这些回复更完整，但错误仍然存在。例如 `teacher_gen_2231b62d5e624e0408107b38` 继续围绕演示里的学业经历作答，`teacher_gen_489f600094112be266974575` 则自行构造研究资助、同伴退出等事件。上述观察来自实际回复，不是把“OFF 没有记忆”自动编码成错误。

因此，后续要分开测量输出完整性、参考事实支持和任务回应程度；不能把字数增加或终于出现结尾当成实质收益。原始人评和裁判比较仍对应旧版本的原回复，本次新回复不会替换旧卷。
