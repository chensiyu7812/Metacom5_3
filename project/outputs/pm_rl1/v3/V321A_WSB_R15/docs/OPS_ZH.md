# 最简操作说明：练习、导出、导入、收件

所有页面都是离线的单个 HTML 文件，用 Chrome 或 Edge 打开即可，不联网。进度只保存在本机浏览器里。

## 1. 练习（先做，用模拟材料）

- **CUR1/CUR2**：打开 `00_练习_CURx_筛查（模拟）.html`。完成 4 条，其中至少 1 条 S1：写理由，在历史中标出“必要”的轮次，回答“是否需要结合多个会话”。然后点“锁定本阶段”，再导出，把文件交给 CUR1。
- **R1/R2**：打开 `00_练习_Rx_评审第一部分Q0（模拟）.html`，完成 3 对，然后锁定本阶段并导出阶段文件，交给 CUR1。CUR1 运行下面的命令，把生成的第二部分文件交还给你：
  ```
  $PY scripts/rl1v3/V321A_r15.py part2 --who R1 --export <阶段文件>
  ```
  你在同一台电脑、同一个浏览器里点“载入后续任务包”，再练习 QH、探针和 F。
  - 在 F 中引用原句：先点一下原句框，再在回复的“英文原文”里点“引用此句”。
  - 在 F 中引用历史依据：先点“设为当前引用项”，再在历史里点“引用为依据”。
- **练习结果不计入任何分析。**

## 2. 导出（三种）

| 什么时候 | 怎么做 | 交给谁 |
|---|---|---|
| 做到一半，想备份或换电脑 | 点右上角“导出进度” | 自己保存 |
| R1/R2 做完 Q0 | 点“锁定本阶段”，在弹窗中点“导出阶段文件” | CUR1 |
| 全部完成 | 锁定全部阶段后点“导出进度”，得到最终文件 | CUR1 |

**提交即锁定，不能回改。** 导出的弹窗里会显示一个校验码，CUR1 收件时核对这个码。

## 3. 导入（换电脑或浏览器数据丢失）

在新电脑上打开同一个 HTML，点“导入进度”，选最后一次导出的文件。

- 新电脑上还没有任何记录：直接恢复。
- 本机记录比导入文件更新：保留本机记录。
- 两边记录不一致（分叉）：导入会被拒绝，请联系 CUR1。

## 4. 正式收件（CUR1）

```
cd /home/tokkio/Metacom5_3-ws-b/project
export TMPDIR=/opt/tokkio-data0/tokkio_runs/wsb_v321a/tmp
PY=/opt/tokkio-data0/tokkio_envs/paper1-py311/bin/python
$PY scripts/rl1v3/V321A_r15.py receive --export <导出文件>    # 每收一个文件运行一次
$PY scripts/rl1v3/V321A_r15.py report                       # 只输出汇总数字，可以转给研究者
```

- **收件命令会拒绝**：
  - 被改动过的文件；
  - 不属于已发放任务包的文件；
  - 英文源文件的导出；
  - 在 CUR1 的 6 条交叉复核收件之前到达的 CUR2 50 条。
- **保管**：逐条标签只保存在 CUR1 的保管目录里，研究者（R1）不打开这个目录。

## 5. PP1 中 Q0 → 第二部分（真实评审，生成之后）

1. R1/R2 锁定 Q0，导出阶段文件，交给 CUR1。
2. CUR1 运行 `part2real --who R1 --export <阶段文件> --replies … --pairs … --salt-file …`。
   - 命令登记该审阅者的 Q0 锚点，并生成 `R1_PP1_第二部分_QH_F.json`。
   - 锚点对不上的第二部分，页面会拒绝载入。
3. R1 在**同一台电脑、同一个浏览器**中点“载入后续任务包”，完成 QH、探针和 F，锁定后导出最终文件，交给 CUR1。
4. R2 按同样步骤独立完成。
