# DP 选材：准备与分工

**现在不做任何正式选择。** 选材要等全部正式 S 标签冻结、研究者确认正式样本之后才开始。

| 项 | 规则 |
|---|---|
| 谁选 | 本组的前缀由本组整理者选：CUR1 选自己的 40 条，CUR2 选自己的 50 条 |
| 选什么 | 只从该前缀全部合法的过去会话（只到此刻之前，按时间排列）中选一份完整会话；也可以选“没有适合的材料”或“无法确定” |
| 要写什么 | 当前需求；理由；单会话覆盖（完整 / 部分 / 无）；还缺什么；有没有时效问题；有没有阶段问题；两项盲态声明 |
| 15% 双人复核 | S 标签冻结后，按已经固定的顺序（`DP_SECOND_SELECTION_ORDER.json`），取 S1/S2 前缀中的前 15%（向上取整），交给另一名整理者独立再选一次 |
| 第二选择怎样记录 | 用单独的角色登记（只把 selector 换成第二选择者），冻结到单独的目录。第二选择不改变、不替换主选择 |
| 先后顺序 | 第二选择者先冻结自己的选择，协调人 CUR1 之后才登记对方的主选择（因为 CUR1 保管收件） |
| 时间 | 全部选择必须冻结在任何生成开始之前；A 的 `check-start` 会在生成前核对这一点 |
| 冲突 | 选择者不能评审同一前缀，别名也算；CUR2 不裁决自己选过（主选或第二选择）的前缀 |
| R1 盲态 | 选材页面、选择文件和冻结回执都不交给 R1/R2；研究者只看汇总数字 |

## 已准备的模板（在 `COORDINATOR_只限CUR1/DP_PREP/`）

- **`DP_ROLES_TEMPLATE.json`**：采用 A 的 DP v2 角色登记格式。selector 已按组填好，Q0/QH/F 的审阅者都填为 R1、R2。
  - 有四项故意留空：people（每人的稳定 person_id）、signed_by、evidence、frozen_at。
  - 这些项留空时，A 的 freeze 命令会拒绝，所以模板不会被误用。
- **`DP_SECOND_SELECTION_ORDER.json`**：15% 第二选择的固定顺序。这个顺序在任何标签产生之前就已经固定。
