- **任务顺序**：表中按顺序编号。每人任务包文件名中的数字就是先后顺序。

## 每个人不能看、不能做的事

- **R1、R2**：
  - 正式评审锁定之前，不看以下内容：模型身份、条件对应关系、Generator 结果清单、对方的判断、整理者的 S 标签和 DP 选择。
  - 不打开翻译批次和译文文件；不当协调人；两人之间不讨论。
  - 研究者是 R1，所以 WS-B 发给研究者的报告只写汇总数字。
- **CUR1**：
  - 不当审阅者，也不当裁决者，因为 CUR1 是非盲的。
  - 必须先锁定自己的交叉复核 6 条，才能收 CUR2 的 50 条。收件命令会强制这个顺序，因为收件由 CUR1 保管。
  - 15% DP 第二选择同理：先冻结自己的第二选择，再登记 CUR2 的主选择。
- **CUR2**：
  - 不当审阅者，不看条件对应关系。
  - 不裁决自己做过 DP 主选择或第二选择的前缀。分发检查会挡住这类前缀，记为“未裁决”，两名审阅者的原始标签照原样保留。
  - PP1 没有 DP 条件，所以 PP1 的全部 F 严重分歧都可以由 CUR2 裁决。
