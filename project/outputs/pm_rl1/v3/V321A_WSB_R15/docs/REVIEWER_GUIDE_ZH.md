# 审阅者说明（R1 / R2）

## 你要做什么

PP1 共 8 组对话。每组有两份候选回复，标为“回复甲”和“回复乙”。

- 你看不到这两份回复是怎样生成的。
- 两名审阅者看到的回复和译文完全相同，左右位置互为镜像。
- 两人各自独立完成，各自导出。

| 部分 | 你看到什么 | 要填什么 |
|---|---|---|
| **第一部分：Q0 即时质量** | 当前会话和两份回复，**没有过往对话** | 每组：哪份回复此刻更合适、差距多大、5 个分项、两份回复是否足够 |
| **第二部分：QH** | 加上完整的过往对话，只到此刻之前 | 以“了解此人过往的支持者”的视角重新比较两份回复。提到历史不加分，没提也不扣分 |
| **第二部分：探针** | — | 只有一题：你认为哪份回复参考了过去的对话（用来检查盲态，不影响评分） |
| **第二部分：F 事实与安全** | 每份回复单独检查，共 16 份 | F1–F8 逐项选“有 / 无 / 无法判断”。选“有”时，要选严重程度，引用英文原句，并在历史中标出依据（F5 可选“查无来源”） |

**估计用时**：练习约 30 分钟，PP1 约 2.7–4.1 小时。可以分几次完成，进度会保存在本机。

## 中文和英文

- 页面每一行先显示中文。下面的“英文原文（权威）”可以展开，英文和中文逐句对照。顶部的“展开全部英文原文”可以一次全部展开。
- **以英文为准。** 中文只帮助阅读。中英文意思不一致时，按英文判断。
- **F 中引用的“原句”必须是回复的英文原文。**
  - 做法：先点一下原句框，再在回复的“英文原文”里点“引用此句”。连续点几句会接在后面。
  - 不是逐字英文原句的内容，提交时会被拒绝。

## 顺序

1. **第一部分（Q0）**：全部提交，点“锁定本阶段”，在弹窗中点“导出阶段文件”，把文件交给 CUR1。
2. **等待 CUR1**：CUR1 核对锚点后，会给你一个第二部分文件（`.json`）。
3. **第二部分**：在**同一台电脑、同一个浏览器**中点“载入后续任务包”。依次完成 QH、探针、F，每做完一个阶段就锁定。
4. **交回**：全部锁定后，点“导出进度”得到最终文件，交给 CUR1。

## 规则

- **独立完成**：不和另一名审阅者讨论，不看对方的文件。
- **评审锁定之前不看**：
  - 模型名称、条件、生成结果清单、任何分数；
  - 整理者的标签和选材；
  - 翻译批次和译文文件。
- **不该看的看到了**：如果意外看到上面任何一项，停下来告诉 CUR1，照实登记。这不是你的错。
- **拿不准时**：选“无法判断”或“一样”，不要硬判。
- **提交即锁定**：提交后不能回改。中途可以随时关闭页面，也请定期导出进度作为备份。

## 练习

1. 打开 `00_练习_Rx_评审第一部分Q0（模拟）.html`。页面顶部有红色横幅：“模拟数据”。
2. 做完 3 对后，锁定并导出阶段文件，交给 CUR1。
3. CUR1 会交还练习用的第二部分文件。载入后，练习 QH 和 F，包括一次“引用此句”和一次“引用为依据”。

练习结果不计入任何分析。
