## 3. 译文：建议与工作量

**建议**：PP1 和正式评审都**不提供译文**，要求审阅者能读懂英文原文。理由：

- F 表的事实核对必须以英文原文为依据；
- QH 需要阅读完整的过往对话，其规模使得翻译不现实（见下表）；
- 避免把译文质量变成新的因素。

如果研究者认为必须提供译文，只翻译**当前会话和回复**（方案 B），过往对话保留原文。

| 方案 | PP1 的翻译量 | PP1 工时（翻译 / 校对） | 正式 FC-MS（中等方案约 57 个前缀）的工时 |
|---|---|---|---|
| A：不翻译（推荐） | 0 | 0 | 0 |
| B：只翻译当前会话和回复 | 当前会话 1,963 词 + 16 份回复约 1,600–3,800 词 | 约 10–17 小时 / 4–6 小时 | 当前会话约 10,700 词 + 171 份回复约 17,000–41,000 词：约 80–150 小时 / 28–52 小时 |
| C：全部翻译，包括过往对话 | B + 36,340 词 | 再加约 105 小时 | 再加约 25 万词，不现实 |

- 工时按人工翻译每小时约 350 词、校对每小时约 1,000 词估计。
- 筛查不提供译文：90 条的 as-of 过往对话合计约 37 万词（含重复阅读）。
- 如果采用方案 B，按 [翻译流程](../../V321A_WSB_R13/pp1_prep/PP1_REAL_REVIEW_PREP_ZH.md) §6 执行：
  - 译者不兼任审阅者；
  - 回复的翻译不知道它来自哪个条件；
  - 逐句映射后冻结。
- **不调用**任何未经研究者批准的外部翻译服务或付费 API；本轮也不启动任何翻译。
