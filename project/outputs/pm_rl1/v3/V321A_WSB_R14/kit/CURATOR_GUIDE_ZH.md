# 整理者操作说明（生成前筛查，表单 S-v2）

**你要做什么**：对每一段“当前会话”，判断要给出一个合适的支持回复，是否需要知道这个人此前的对话。你看不到任何回复，也不需要评价任何模型。

## 打开与核对

1. 用电脑上的 Chrome 或 Edge 打开协调人发给你的 HTML 文件。不需要联网，也不要用手机。
2. 页面顶部显示你的代码和“任务包”校验码的前 8 位，请与协调人核对。
3. 红色“模拟数据”横幅只会出现在练习包上，正式任务包没有。

## 每一条怎么做

左侧是当前会话；右侧是此刻**之前**的全部过往对话，按时间排列，可以搜索，也可以全部展开。原文是英文。

| 题 | 怎么答 |
|---|---|
| S-1 需要标签 | **S1 必要**：不知道这段历史，回复很可能答错、答非所问或伤害对方。<br>**S2 相关**：历史与此刻有关，但不必主动提。<br>**S0 无关**：有历史，但与这一轮无关。<br>**无法判断**：确实判断不了时选它，不要勉强 |
| S-2 理由 | 选 S1 时必填：写出“如果回复者不知道这段历史，回复会怎样出错” |
| S-2b 是否必须结合多个会话 | 选 S1 时必填，S2 时可选：一个会话即可 / 必须结合多个会话 / 无法判断 |
| S-3 风险 | 可多选：信息可能已过时；可能诱发不当建议；对方曾拒绝或尝试失败；涉及第三人、容易混淆；都没有 |
| S-4 片段标注 | 在右侧历史中逐句选“标注…”：必要 / 相关但可选 / 回复不得与之矛盾。选 S1 时至少标一条“必要” |

- **没有历史的前缀**（对方的第一次对话）：只需要确认“此前没有任何个人历史”。
- **顺序**：同一个人的前缀按时间先后排列，请按顺序做。这样你只需要增量阅读，也不会先看到更晚的对话。

## 提交、锁定、导出

- 每次选择都会自动保存为草稿，可以随时关闭浏览器，再打开时会恢复。
- 点“提交并锁定”后，这一条**不能再改**。
- 全部提交后点“锁定本阶段”，然后立即点“导出阶段文件”，把文件发给协调人。中途也可以随时点“导出进度”备份。
- 换电脑时，在新电脑上打开同一个 HTML，点“导入进度”选择你备份的文件即可。

## 注意

- 不要编辑导出的文件，也不要转发给协调人以外的任何人；不要截图或保存对话内容。研究结束后删除本地文件，并清除浏览器中本工具的数据。
- 对话可能涉及压力、焦虑等情绪话题。感到不适可以随时暂停或退出。
- 你的标签只在审计侧可见，评审者和生成模型都看不到；你也不会看到任何回复或模型结果。
- 遇到工具报错或任何不清楚的地方，截图发给协调人，不要自己修改文件。
