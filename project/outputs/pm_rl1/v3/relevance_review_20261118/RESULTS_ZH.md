# 词面 v0 分层检索审阅包（开发材料，非独立金标）

原 `relevance_dev_20261118` 的12条检查、SHA和开发者判断逐字节保留。本包沿用已固定B1开发覆盖前缀（fold1–5），每个前缀检查四头，并保留原无过去来源边界例；不使用fold6、未来终点评分或回复质量筛选，不改变v0排序。

实际生成 **83** 条可复核样本：ME/MP/MS各21、RS20；15个owner、16种cutoff rank（含0和20）、5个开发fold。77次读取得到正文，6次明确 `unavailable`。这不是可读率的独立总体估计，也不是召回准确率。

- `REVIEW_SAMPLES.jsonl`：每条有当前完整可见前缀、最后三轮query/version、query原文跨度、完整合法候选的ID/排序/词面分数/时间/阶段/状态、实际top-1 ReadingView正文、原生token数和来源跨度。无候选同样保存过滤条件和失败原因。
- `CANDIDATE_RECORDS.jsonl`：1876个被候选集合引用的完整ResourceRecord，含原文/跨度/时间/owner/family/review等；通过ID连接可核查全部候选正文，不只看top-1。全量候选集合与当前固定bank的合法过滤和v0排序逐项测试一致。
- `BLIND_REVIEW.jsonl`：打乱顺序、隐藏开发者标签和检索分数的正文审阅表。来源跨度仍可供核对；这只是遮蔽开发判断的材料，不宣称双盲研究。
- 每条 `reviewer_fields` 都是 `unreviewed`：主题相关、时态有效、是否现在需要读/提及、RS适用性、误导建议风险、判断引文、审阅人和理由分别登记。尚无人评。

必须区分的失败类型沿用原开发发现：

1. 有合法候选但词面相似不足以判定同一事件：p11当前家庭经济/希望倾听，ME却命中John分手。
2. 主题相关但阶段已过去：p9已搬迁，ME仍是是否接受远方工作的犹豫；只能作为过去阶段。
3. 相关但当前无需主动提及：告别致谢或已在当前可见上下文说明的孤独，不需要机械复述资源。
4. 真正无严格过去来源：首会话边界的MP/ME/MS；与有来源但不相关分开。
5. 可能误用：ME中的未来意向不能当已完成；RS案例中的supporter自我经历、养狗建议不能复制成助手经历或专业建议。外部案例与当前情境适用性需另核。

新样本覆盖有/无合法候选及多个owner、时间阶段和资源头；语义判断仍待研究者复核。原12条标签是开发者诊断，不应拿它们训练后再报告同一批“准确率”。没有新增专业方法卡、未经证实关系传播、BGE/BM25/RRF或Generator调用，未声称检索/回复质量提高。
