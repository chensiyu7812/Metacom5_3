# DP-MS 规则修订：人工选材为主，Rule-DP 为次要基线

- **研究者倾向**：正式采用人工选材，而不是按“必要”片段的数量自动排序。理由是：相关片段最多，并不等于最能改善此刻的情感支持。
- **本文件的内容**：把 #22 协议 A4 的提议与 A 在 #21 中的人工选材工具对齐，列出工具还缺什么，并给出 10%–20% 双人重叠的一致性检查方案。
- **不修改**：#22 的协议文件（`27df254f`）不改；本修订记录在 [研究决定回执候选](../decision/RESEARCHER_DECISION_RECEIPT_ZH.md) 中。

## 4. 10%–20% 双人重叠选材的一致性与分歧检查

**抽样**：

- 从需要 DP 的前缀（S1 与 S2；S0 的 DP 只用作打扰检查，不参与抽样）中，用审计侧的 salt 按哈希顺序抽 15%。
- 每名主选择者至少 2 个，PP1 的 8 个前缀中至少 1 个。
- 抽样名单在任何选择开始之前登记。

**做法**：

- 第二名选择者使用同一个工具和同一个选材包，看不到第一人的选择，回执写到单独的 `overlap/` 目录。
- 第二人的选择**不参与生成**，也不改变已经锁定的主选择。

**指标**（只作描述）：

| 指标 | 定义 |
|---|---|
| 决定一致率 | 两人都选 selected / none_suitable / uncertain 的一致比例 |
| 同一会话率 | 两人都 selected 时，选中同一会话的比例 |
| 覆盖判断一致率 | `single_session_coverage` 的一致比例；样本量允许时报告 Cohen κ |
| 与 Rule-DP 的重合率 | 主选择与 Rule-DP 选中同一会话的比例 |

**分歧处理**：

- 逐条记录两人的理由，由不参与该前缀审阅的第三人归类：材料理解不同 / 需求判断不同 / 多会话无法单选 / 其他。
- 归类只用于描述 DP 条件的可靠性，不重新选择，也不改变已锁定的结果。

**报告**：在 FC-MS-1 的方法部分报告上述指标。若同一会话率很低（例如 < 50%），在讨论中说明 DP-MS 是“一名选择者的判断”，而不是唯一确定的“最佳历史”。

## 5. 时间与人力

- 每个前缀选材约 3–6 分钟，因为选择者已经读过该 owner 的历史（与筛查同一人、同一顺序）。
- PP1 的 8 个前缀约 0.5–1 小时。
- 正式样本按中等方案约 50–70 个前缀，约 3–7 小时；重叠部分另需 15% 的工时。
