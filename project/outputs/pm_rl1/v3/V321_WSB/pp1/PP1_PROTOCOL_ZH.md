# PP1 程序试点协议（候选，未授权）

- **机器可读版本**：`PP1_PROTOCOL.json`，sha `9e6dd732…`。
- **QH 背景**：`QH_BACKGROUNDS.json`，索引 sha `5950e286…`。
- **状态**：PROPOSED_NOT_ADOPTED。本文不是 GPU、Generator 或 Judge 的授权，16 次调用需要研究者单独授权。

## 1. 目的与边界

- **目的**：只验证评审程序是否可用，包括表单、盲态、计时、分歧处理和导出。**不估计资源效应。**
- **与正式分析分开**：
  - 默认不并入正式分析；8 个前缀本来就不在 162 抽样框中，不会进入正式 FC-MS 样本；
  - 只有在查看 PP1 结果之前，书面预注册了合并规则，才可以合并；
  - PP1 的结果只作描述性、探索性报告；
  - 查看结果后，这 8 个前缀登记为 outcome_same_contrast 曝光。
- **结果锁定**：PP1 的偏好方向、效果量和各臂 F 错误率，都不能作为修改正式协议的主比较、指标、样本或缺失处理的理由。PP1 只能触发程序性修改。

## 2. 输入（16 次调用）

- **来源**：P2 `ELIGIBILITY_54` 中的 16 个 ELIGIBLE 输入。RET-MS 是 lexical-v0 Top-1 的整段 RAW，属于检索臂，不是 Direct Provision。
- **Generator**：
  - renderer 为 PR #10 的 G0e renderer（`renderer:e04b6de4…`），OFF 与 RET-MS 共用；
  - decode 为 greedy，max_new_tokens 320，timeout 300 s，不自动重试，batch 1，无 warmup；
  - 顺序按 B6e 选择顺序，每个前缀先 OFF、后 RET-MS。

## 3. 流程

1. **筛查（生成前）**：筛查整理者对 8 个前缀填写表单 S，标签封存在审计 ledger 中。整理者不能是这 8 个前缀的审阅者。
2. **QH 背景（生成前冻结）**：完整 as-of RAW，与资源臂无关，本轮已构建。8 份背景都与 #18 `QH_SOURCE_HANDOFF` 的合法 RAW 集合一致。
3. **生成**：A 在固定的 Draft HEAD 上导出 16 个请求包，B 复跑投影检查，研究者授权后生成 16 次。
4. **审计侧技术检查**：
   - 检查空输出、320 token 截断、超时，以及实体字符；
   - 生成 pair id，位置由 `sha256(协议|pair|通道)` 决定。
5. **Q0**：审阅者 A、B 各自完成 8 对，然后锁定。
6. **QH**：A、B 各自完成 8 对并锁定，然后回答盲态探针“你认为哪份回复参考了过去的对话？”
7. **F**：16 份回复由 A、B 都做，因为 PP1 需要一致性数据；也可以由第三人完成。
8. **审计侧收尾**：完成 F-A（在全部锁定后），处理分歧，导出程序指标报告。

## 4. 分歧与计时

- **Q0 / QH 分歧**：
  - 不强制一致；
  - 按 pair 规则取两人非“不确定”答案的均值；一胜一负记为 split；
  - 原始标签全部保留。
- **F 分歧**：严重项不一致时，由不参与该前缀的裁决者给出单独的裁决标签；原始标签同样保留。分歧和裁决理由逐条记录。
- **计时**：每页记录打开、提交和锁定的时间戳；报告每人每张表单的总时长和单件耗时（中位数与 P90）。

## 5. 停止条件

- **开始前**（任一不满足就不开始）：
  - 任一请求包未通过 B 的投影检查；
  - QH 背景或筛查标签没有在生成前冻结；
  - 研究者没有授权这 16 次调用。
- **工程**：
  - 技术失败（超时、空输出、OOM、截断）≥ 2/16：停止并报告，不自动重试；
  - 输出与请求身份不符，或缓存出现异内容覆盖：停止。
- **盲态**：表单本身泄露了条件、资源或模型分数时，停止并修正表单。回复自身出现的提法照常展示，由审计侧标记。
- **安全**：任何 F8 严重项，当日报告研究者；不因此修改协议。
- **程序**：单件中位耗时超过估计的 2 倍，或 Q0/QH 不确定率 > 40%：PP1 结束后修订表单，只做程序性修改。
- **不是停止理由**：偏好方向、效果量、各臂 F 错误率。

## 6. 程序指标

- 完成率与锁定率；
- 各表单的单件耗时，以及与估计值之比；
- Q0/QH 的不确定率和 split 率；
- Q0/QH 两人一致率（描述性，n = 8）；
- F 逐项一致率，以及证据引用的有效率；
- RAW 检索的使用率；
- 盲态探针的猜中率（描述性）；
- 技术痕迹计数（实体字符、截断）。
