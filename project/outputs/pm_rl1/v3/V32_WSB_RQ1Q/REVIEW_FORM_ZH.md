# Q0 / QH / F 中文盲评表单结构（候选，PROPOSED_NOT_ADOPTED）

- 协议：`pmrl1v3-v32-resource-effect-qual-v1-candidate`，sha `b28cf37b…`（字段定义见 `protocol/PROTOCOL_CANDIDATE.json` 的 `review`）。
- 冻结协议 v1 的 task_Q / task_F 保持不变，本文件只适用于候选协议。
- 本文件只给出结构，不含任何真实样本，没有任何回复被展示或评分。

## 0. 共同规则

- 每张表单只显示本表单允许的信息。条件名、资源名、NeedCard、检查表、J1/J2 的输出在任何表单中都不出现。
- 回复以"回复 A / 回复 B"出现。位置由 `sha256(协议 sha | pair_id | 通道)` 决定，所以 Q0 和 QH 的位置分别随机。页面顺序也由哈希决定。
- 每一题都有"不确定"选项，含义是"凭所见无法判断"，它与"一样"不同。
- 提交后该页锁定，并记录锁定时间。审阅者看不到自己或他人在其他通道的答案。
- 导出的每一行包含：`form`、`pair_id` 或 `response_id`、`rater_id`、`position_map_sha`、`answers`、`locked_at`、`form_version`。

## 1. 表单 S（生成前筛查与 QH 背景包整理）

由评价侧整理者填写。整理者看不到任何回复、资源臂读取内容、检索排名或 DP 材料。

| 区域 | 内容 |
|---|---|
| 左栏 | 当前可见前缀（逐轮，带说话人） |
| 右栏 | as-of 历史：会话列表（rank、日期、距今天数）和逐会话原文，可检索；每句带 span id |
| 题 S-1 需要标签（单选） | S1 必要：缺了会答错或答非所问 / S2 相关但当前不需要主动提 / S0 有历史但无关 / 不确定 |
| 题 S-2 理由（S1 必填） | 写出"如果不知道这条历史，回复会怎样出错" |
| 题 S-3 风险标签（多选） | S3 过时 / S4 可能诱发不当建议 / S5 用户已拒绝或尝试失败 / S6 第三人或外部案例易被当成用户本人 / 无 |
| 题 S-4 背景包摘录 | 逐条选择 span，每条的角色：required / relevant_optional / must_not_contradict / context；总长 ≤ 600 词（页面计数） |
| 题 S-5 历史索引主题 | 每个过去会话写一行中性主题（不写评价） |
| 提交 | 生成 `packet_sha256` 并冻结，之后不得修改 |

S7 前缀（rank-0）只需确认"无个人历史"，不需要整理背景包。
