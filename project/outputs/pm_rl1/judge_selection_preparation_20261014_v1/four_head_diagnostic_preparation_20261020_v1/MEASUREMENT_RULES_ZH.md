# 测量实验与事先判读规则

状态：PROPOSED RESEARCH CHANGE — NOT AUTHORIZED。现有v2的q/m/U、成本系数和语义提示均不修改；采用最近同期比较的联合基线（历史累计2次语义修订），不采用六参照校准臂。历史累计3次修订仍如实保留。测量和训练入口例外单独版本化。

## 本阶段的三个问题

1. 完整来源、真实公开观测、真实G/J反馈及两次在策略更新之间重新采样的PPO批次能否接通？检查GET零G/J调用、合法mask、STOP绑定、旧log-prob重算、pending不更新、缓存及断点记录。
2. 在本固定清单上，反馈缺陷的种类、影响范围和未完成覆盖是什么？对每份唯一反馈复核完整回复和合法来源；共享OFF只计一个测量，保留其影响哪些对照的依赖关系。
3. 在6个预先固定的dev输入上，代理回报、获取行为和来源可核查问题是否同向变化？OFF、FixedRS1、学习前/后策略全部保留，不选分数上涨的案例展示。

这是对已知不完美测量的运行与早期偏差诊断，**不是新的裁判准确率验证，也不是聚合降噪试验**。缓存固定一次抽样，不消除系统偏差；相同终点的复用不计新独立测量。

## 反馈分类与唯一允许的例外

| 状态 | 本阶段处置 | 不允许的解释 |
|---|---|---|
| 机械有效，分析者未确认核查错误 | 保留原q/m，用作带标记的弱代理 | 分析者没发现错误不等于独立合格证据 |
| 复核未决歧义：表达的双读边界 | 标记具体主张、原条款、两种读法及未决原因后，可保留原数值用于诊断 | 不选更有利读法、不补唯一金标 |
| 复核未决歧义：严重度边界 | 保留来源关系与严重度争议的区别，可保留原数值用于诊断 | 不把unsupported自动升级severe |
| 复核未决歧义：相邻q锚点 | 保留具体当前需求及满足/遗漏理由，可保留原数值用于诊断 | 普通q相邻分歧不自动算实质核查错误 |
| 身份澄清责任的合同缺口 | 单列旧生成器/旧裁判收到的要求，带标记诊断 | 不把后来补充的主动澄清要求倒算为旧明确违约 |
| 已确认的裁判核查错误 | 停止本阶段，在该批更新前保留结果 | 不能以同时存在歧义抵消；不改分或另问模型追分 |
| 模型自身unknown | 原q/m保持null；pending，停止本阶段派发和更新 | 不补0、不算平局、不删难轨迹 |
| 技术失败、来源/身份绑定失败、截断或无完整usage | 停止，保留原始片段及未结责任 | 不从thinking提取答案、修内部JSON、自动重试 |
| 尚未完成分析者核查 | 等待协调者核查；不更新、不另发人评题卷 | 不把“未复核”自动标成“无问题” |

“已确认错误”特指**裁判的测量判断**，必须列出具体主张、原判据、合法来源ID和原文：漏掉可核查主张、错认人物/时间、证据关系错误、无依据指控、可由原条款证明的严重度违例、原无依据等义差异。回复本身有明确错误但裁判识别正确，仍可提供负反馈。不得用不喜欢该策略或相邻q差，代替错误证明。

同一记录兼有已确认核查错误与歧义时仍停。允许的四类歧义以外不能凭自由文字扩大例外。`coordinator_reviews/<record_identity>.json`只存分析者复核，不是新的独立人评；核查必须绑定原结果哈希，原分数不覆盖。更新前再次核验复核记录。

## 固定比较、统计和判读

固定32训练轨迹（24个前缀、12位来源owner，8个预定重复轨迹），6个dev前缀来自另外3位既有dev owner；学习前/后采用同一greedy策略读出规则，FixedRS1预先固定为取一条RS后STOP，不叫FixedDev。所有四头顺序动作仍合法；不得因未测或难判而删动作。

每个dev前缀展示OFF、FixedRS1、学习前、学习后四种终点；同一输入/终点可缓存。分别列：GET次数及类型、token成本、停止时机、q/m、ΔU、净回报、技术状态、模型unknown、复核歧义、已确认核查错误，以及执行器的事实/归属/任务响应问题。若一个OFF影响多个比较，按同一反馈记录链接，不虚增独立案例。

报告所有计划槽位及缺失原因。可比较数量、未决数量、覆盖率和排除原因同时列出。没有新的人类配对判断时，方向一致性分母记为缺失，不能用Codex复核或旧Du派生替代；旧人评仅在回复、当前语境、来源、说明版本及换侧映射全部一致时引用，不能从单条q/m推导偏好。

`--report`给出原分数和代数敏感性：在合法q边界内单边扰动一档、分别替换m档，观察净收益方向是否变化。它只是压力测试，不断言替代档合理、不产生置信区间、不进入PPO。若某一歧义的可接受数值范围没有来源支持，保留未知，不人为制造区间。独立人评确认的多种可接受回复不等于强制q/m相同。

判读事先固定为：

- 工程链完整且反馈有充分覆盖：只说明真实管线可以工作；32轨迹不提供效果或资格证明。
- 代理回报上升、来源核查下的明确误用也增加：记录代理与任务结果背离，定位具体关系错误，不能宣布改善。
- 成本下降、任务表现无法分辨：只报初步成本变化；不以“不显著”声称维持质量。
- 主要停在模型unknown/技术失败：记录测量覆盖/交付问题，不算PPO失败。
- 出现确认的裁判核查错误：该批不更新，终止本阶段；形成有限的主张—人物—行动阶段—来源关系监督缺口，不再自动加提示或换候选。
- 全STOP或无明显变化：检查实际资源机会、执行器利用及观察表示；不以PPO必须正收益为条件，不为创造赢家改题。

来源复核覆盖本阶段已完成的全部唯一反馈，最多80条，由分析者执行并留痕。本次**新增研究者标注任务0**，不重发旧7组或8条。若dev整体可接受性仍需真人参考，可在本阶段结束时一次提出最多12个既定对照、最多60分钟的后续申请；现在不发包、不启动，也不挪用原训练人工12条预留。

## 与测量改进和正式研究的衔接

关系核查能力、自然可接受性、歧义的数值处置、完整交付分别评价，不能只看U或整体吻合率。若缺陷是明确的主体/时间/行动关系，下一干预应围绕有限关系监督或核查器适配，训练与检查按来源组分开；已有模型输出和分析者意见不能直接当独立金标。若主要缺陷是双读/严重度边界，则比较测量定义或不确定性处置，不能再要求模型靠提示挑出“正确”单值。

本批不实施上述新模型或量表改动。进入正式研究还须落实测量用途和误差容忍的预先合同、独立评价来源，以及BC／OneShot／NoText等原比较。旧59次验收只是条件性的预留，不声称这套诊断例外已自动适用旧验收或绕过正式评价。
