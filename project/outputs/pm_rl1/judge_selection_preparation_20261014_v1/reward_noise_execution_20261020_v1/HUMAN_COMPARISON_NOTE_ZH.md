# 人工方向与成本的分析口径

本说明在人工答案尚未返回、固定48槽仍运行时记录。它澄清原申请中“人评方向”的比较对象，不改变任何请求、顺序、提示、分数、聚合、预算或推进条件。

人工页不展示资源条件或成本。因此，人类的A/B较好或相当判断首先对应回复本身的质量与重要问题，不是已扣资源成本的收益大小。

- 人工明确方向：与单次/两次平均的 `U_ON−U_OFF` 正负方向比较，记录错误、模型平局、未知/未完成。模型平局遇到明确人类方向不当作一致。
- 人工相当：单列与 `U_ON−U_OFF=0` 的对应，不能用 `D<0` 断言裁判与人类不一致。若两条回复等效，D因资源成本为负、选择OFF正是预期行为。
- 人工未知或尚未作答：不进入方向一致性的分母，不补成平局。所有计划8组及排除原因仍披露。
- 人工有方向没有给出效用差的大小，不能把其方向直接当作精确净收益金标准。D表仍按原公式独立报告。当前固定成本均小于两次平均的最小正U档差，但这不是所有未来轨迹的保证。

严重风险与事实依据单列；不以一般偏好或均分推翻有来源的风险。研究者的单人开发参照不是第二位独立评审，也不构成独立验收。
