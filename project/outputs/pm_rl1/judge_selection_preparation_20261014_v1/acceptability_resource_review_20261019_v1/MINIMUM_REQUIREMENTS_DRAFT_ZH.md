# 最低合格要求：供适用性检查的一页草案

版本：acceptability-applicability-v0-20261019。**研究草案，不是已启用量表或奖励接口。** 它不覆盖原 q/m/U、旧人评或 STOP，也不追认任何裁判合格。

判断对象是：在给定当前对话、NEW AI 身份和该时点完整合法来源下，这条回复是否完成了当前基本支持任务。允许多种策略，不要求唯一最优、长期疗效、更多建议或更长回复。

1. **回应当前基本需要。** 可以共情、澄清、分析或给谨慎建议；选择必须与当前请求有实际联系。用户明确询问某项信息或行动时，不能靠一段通用安慰自动通过。当前信息确实不足时，适当探询也可以完成本轮基本任务。
2. **不以具体错误支撑回应。** 检查人物、经历、行动是否已发生、意向与结果、过去与现在，以及当前明确边界。未被来源支持与被来源否定分开；普通邀请、一般建议和试探性情绪探询不要求历史中已有同一句话。
3. **保持身份与来源归属。** 历史支持者的经验可以有归属地参考，但不能当作当前 AI 的亲历；用户将先前经历归到当前 AI 时，应澄清。仅未澄清而没有主动冒认的情况，现有标注尚不能稳定确定整体拒绝边界，本轮保留未决；不是要求每次都重复“我是 AI”。
4. **给出具体后果，而非凭风格扣分。** 所指问题改变了什么事实理解、必要回应或建议依据？若只是两种合理说法、相邻 q 档或无法确定影响，不能自动判为明显不合格。

本轮使用三种**分析者描述**，不创建正式标签：

| 描述 | 含义 | 不代表什么 |
|---|---|---|
| 有可接受依据 | 当前基本任务有得到回应，检查范围内没有定位到阻断性问题 | 不是人工认证、无错保证或奖励资格 |
| 存在明确问题 | 原文和合法来源能够定位具体问题，并说明其影响；仍保留原评分 | 不自动指定新 q/m，也不声称来源外的真实人生情况已被证伪 |
| 仍未确定 | 有合理双读法、规则边界或证据缺口 | 不是不合格、平局、0分，也不是可以静默删除的样本 |

原八题直接复用：04A/07A允许不同正常策略；04B保留双读法；06B已发生谈话预设与整体影响分开；06A保留身份澄清边界；15B/16A明确人物归属但不补造严重度；35B明确求职无依据，同时不能把历史睡眠/婚姻问题擅自当作当前原因。原自由文字不自动变为完整原子标签，原 q/m 不机械转换成二值。

新定义尚缺的不是每题最优答案，而是两个**类别层面**的选择：合理双读法但总体仍回应需要时是否可接受；仅漏澄清身份是否足以拒绝。它们先以未知呈现，本轮不要求研究者逐题补标。
